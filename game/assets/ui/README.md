# อาร์ตของ UI

ไม่ใช่อาร์ตตัวละคร — `assets/characters/` เก็บ**อัตลาส + JSON ที่ท่อ build สร้าง**
ของที่นี่เป็นภาพเดี่ยวที่ CSS เอาไปใช้ตรง ๆ

แยกโฟลเดอร์เพราะ service worker โหลด `assets/characters/` แบบ "เจอแล้วค่อยเก็บ"
(30 MB โหลดล่วงหน้าไม่ไหว) แต่ของที่นี่เล็กและต้องเห็นตั้งแต่เปิดแผงครั้งแรก
จึงอยู่ในรายการโหลดล่วงหน้า

| ไฟล์ | ใช้ที่ไหน |
|---|---|
| `soon_01.png` | เงาตัวละครที่ยังไม่ปล่อย ในแผงเลือกตัว |

`soon_01.png` ทำจาก `art_reference/characters/soon01_flowers.jpg` (ท่ากลาง)
แปลงเป็นเงาสีครีม `#e8e2d6` บนพื้นโปร่ง — เงา**สว่าง**บนพื้นมืดอ่านออกกว่าเงาดำ

โชว์เป็นเงาไม่ใช่รูปเต็มโดยตั้งใจ: บอกว่า "มีคนมาเพิ่ม" โดยไม่ผูกมัดกับอาร์ตชุดสุดท้าย
ซึ่งยังเปลี่ยนได้จนกว่าจะประกอบชีตเสร็จ
