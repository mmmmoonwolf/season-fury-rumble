เปิดไฟล์ตรงๆ ไม่ได้

เกมนี้ใช้ ES module เบราว์เซอร์เลยบล็อกเมื่อเปิดแบบ file:// ต้องเปิดผ่าน local server

เปิด terminal ที่โฟลเดอร์ game แล้วรัน:

npx serve

แล้วเปิด http://localhost:3000

ไม่มี Node ใช้ Python แทน:

python3 -m http.server 8000
