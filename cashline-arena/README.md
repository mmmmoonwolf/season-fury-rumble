# Cashline Arena

เกม FPS 3D บนเว็บ แนวเกมโชว์ยิงชิงเงิน สายป่วน ทำด้วย three.js
ห้องละ 4 คน ช่องว่างใช้บอทเติม สนามพังได้แทบทั้งหมด ตัวละครเป็นชิบิน่ารักๆ จากคนในออฟฟิศ 8 คน

## มีอะไรในเกมตอนนี้

| | |
|---|---|
| โหมด | **Cash Rush** เปิดตู้เซฟ ขนกล่องเงินไปฝากที่จุด CASHOUT ทีมแรกถึง $20,000 ชนะ<br>**Platform Push** ยืนบนแท่นที่วิ่งบนราง ดันเข้าประตูฐานศัตรู |
| รูปแบบทีม | Cash Rush: 1v1v1, 1v1v1v1, 2v2 · Platform Push: 2v2, 1v1 |
| คลาส | Light (เร็ว พุ่งหลบ) · Medium (ระเบิดเจาะ ฮีลทีม) · Heavy (ค้อนยักษ์ RPG ชาร์จชน) |
| ตัวละคร | 8 คนจากออฟฟิศ เปลี่ยนแค่หน้าตา ไม่มีผลกับพลัง |
| ความป่วน | ตายแล้วกระเด็นเด้งไปไกล ระเบิดเป็นชิ้นๆ โดนค้อนโฮมรันออกนอกสนาม หรือพุ่งขึ้นฟ้าแบบจรวด · ค้อนกับระเบิดดีดคนกระเด็น · คำว่า "ปั้ก!" "โป๊ก!" ตอนยิงโดน · กด T โชว์ท่าประจำตัว |
| แมพ | Studio Plaza 96×96 บล็อก ตึก 2–3 ชั้น สะพานลอย ซีกซ้ายขวาเหมือนกันเพื่อความยุติธรรม |

## เริ่มพัฒนาต่อด้วย Claude Code

1. แตกไฟล์ zip ไว้ในโฟลเดอร์โปรเจกต์ เช่น `Desktop\projects\cashline-arena`
2. เปิด PowerShell ในโฟลเดอร์นั้น แล้วพิมพ์ `claude`
3. Claude Code จะอ่าน `CLAUDE.md` เองอัตโนมัติ ไฟล์นั้นอธิบายโครงสร้างโค้ดทั้งหมดไว้แล้ว
4. ประโยคแรกที่แนะนำให้พิมพ์:
   > อ่าน CLAUDE.md แล้วสรุปโครงสร้างเกมให้ฟัง จากนั้นสร้าง git repo, commit แรก และ push ขึ้น GitHub ชื่อ cashline-arena (private)

   ถ้ายังไม่ได้ติดตั้ง GitHub CLI ให้ Claude Code ช่วยติดตั้งและล็อกอิน `gh auth login` ก่อน

## รันในเครื่อง

ต้องมี Node.js (มีอยู่แล้วถ้าติดตั้ง Claude Code ผ่าน npm)

```bash
npm run dev
```

แล้วเปิด

- `http://localhost:8765/index.html` เล่นกับบอท
- `http://localhost:8765/mp-local.html` เปิด 2 แท็บขึ้นไป เพื่อลองโหมดออนไลน์ในเครื่องเดียว
- อยากลองออนไลน์ผ่าน WebSocket จริง ใช้ `npm run online` แทน (ดูหัวข้อถัดไป)

ทดสอบอัตโนมัติ (ครั้งแรกต้อง `npm install` และ `npx playwright install chromium`)

```bash
npm test
```

## เล่นออนไลน์ผ่าน WebSocket (นอก Claude)

มีเซิร์ฟเวอร์ WebSocket ในโฟลเดอร์ `server/` ทำหน้าที่แค่ส่งต่อข้อมูลระหว่างผู้เล่นในห้องเดียวกัน
ตัวเกมยังคำนวณบนเครื่องเจ้าของห้องเหมือนเดิม (เจ้าของห้องออก เครื่องอื่นรับช่วงต่อเอง)

### ลองในเครื่องตัวเอง

```bash
npm install
npm run online
```

เปิด `http://localhost:8765/` สองหน้าต่าง (หรือให้เพื่อนในวง LAN เปิด `http://<IP เครื่องเรา>:8765/`)
คนหนึ่งกด "สร้างห้องส่วนตัว" อีกคนกรอกรหัสห้อง 4 ตัวแล้วกด "เข้าห้อง" หรือกด "หาห้องอัตโนมัติ" ทั้งคู่

### ขึ้นเซิร์ฟเวอร์จริง (เช่น Render, Railway, Fly.io)

ตั้งค่าเป็น Node web service แบบนี้

| ช่อง | ค่า |
|---|---|
| Root directory | `cashline-arena` |
| Build command | `npm install && npm run build` |
| Start command | `npm start` |
| Health check | `/healthz` |

เซิร์ฟเวอร์เปิดทั้งหน้าเกมและ WebSocket ที่ `/ws` บนพอร์ตเดียวกัน (อ่านจาก `PORT`) ส่งลิงก์ให้เพื่อนได้เลย

### ถ้าหน้าเกมอยู่ที่อื่น (เช่น GitHub Pages)

GitHub Pages เปิด WebSocket ไม่ได้ ต้องมีเซิร์ฟเวอร์ข้างบนอยู่แล้วชี้ไปหา ได้สองวิธี

- ฝังที่อยู่ตอน build: `WS_URL=wss://ชื่อเซิร์ฟเวอร์/ws npm run build` แล้วเอา `dist/index.html` ไปขึ้น
- ใส่ในลิงก์: `https://…/index.html?server=wss://ชื่อเซิร์ฟเวอร์/ws` (เบราว์เซอร์จำไว้ให้ ใส่ `?server=off` เพื่อล้าง)

ถ้าต่อเซิร์ฟเวอร์ไม่ได้ เกมจะขึ้นว่าออนไลน์ไม่พร้อม และยังเล่นกับบอทได้ตามปกติ

### ข้อควรรู้

- ทุกคนต้องเปิดเกมเวอร์ชันเดียวกัน (เซิร์ฟเวอร์เดียวกันจะเสิร์ฟเวอร์ชันเดียวกันให้อยู่แล้ว)
- เครื่องผู้เล่นตัดสินว่ายิงโดนเอง เหมาะเล่นกับเพื่อน ยังไม่เหมาะเปิดให้คนแปลกหน้าเล่น
- ทดสอบอัตโนมัติผ่าน WebSocket จริง: `npm run test:ws`

## แก้ตัวละคร

- **ชื่อเล่น**: แก้ใน `src/core.js` ตรง `CHARS` (ตอนนี้เป็นชื่อชั่วคราว)
- **หน้าตา**: แก้ใน `src/chars.js` ตรง `CHAR_VIS` ทั้งสีผิว ทรงผม สีเสื้อ ลายเสื้อ แว่น และคำพูดตอนกด T

| id | ชื่อชั่วคราว | จุดเด่น |
|---|---|---|
| bob | บ๊อบ | ผมบ๊อบหน้าม้า เสื้อดำ ยีนส์ |
| rock | ร็อกเกอร์ | ผมยาว แว่นกันแดดบนหัว มินิฮาร์ต |
| sock | ถุงเท้า | ผมยาว เสื้อกรม ถุงเท้าดำ |
| specs | พี่แว่น | แว่นกลมกรอบน้ำตาล หัวเอียง |
| smile | ยิ้มหวาน | ผมรวบ เสื้อแขนกุดลาย |
| polo | สตาฟ | เสื้อโปโลดำมีโลโก้ นาฬิกา |
| grey | หนุ่มเทา | ผมหยักศก เสื้อสเวตเตอร์เทา |
| pine | สับปะรด | ผมทรงกะลา แว่นใส เสื้อลายสับปะรด |

## เรื่องที่ควรรู้

- เล่นออนไลน์ได้สองทาง: เปิดผ่านลิงก์ Claude Artifact (ต้องล็อกอิน) หรือผ่านเซิร์ฟเวอร์ WebSocket ของเราเอง (หัวข้อด้านบน)
- ทุกคนในห้องต้องใช้เวอร์ชันเกมเดียวกัน เพราะข้อมูลการพังของแมพอิงขนาดแมพ
- ข้อความในเกมเป็นภาษาไทยทั้งหมด

## ศัพท์ที่ใช้ค้นต่อ

- **host-authoritative netcode** — ให้เครื่องหนึ่งเป็นตัวตัดสินเกม
- **host migration** — สลับเจ้าของห้องอัตโนมัติเมื่อคนเดิมออก
- **ragdoll** — ตัวละครกระเด็นตามฟิสิกส์ตอนตาย
- **knockback** — แรงดีดตอนโดนตี
- **voxel** — โลกที่สร้างจากบล็อกลูกเต๋า
- **WebSocket relay** — เซิร์ฟเวอร์ส่งต่อข้อมูลระหว่างผู้เล่น
- **glTF / GLB** — ไฟล์โมเดล 3D ที่ three.js ใช้ได้ดีที่สุด
