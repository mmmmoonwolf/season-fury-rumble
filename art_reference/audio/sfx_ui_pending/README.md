# เสียงปุ่มเมนู — ต่อเข้าเกมแล้ว

ไฟล์ย้ายไป `art_reference/audio/sfx_raw/` แล้ว (ที่เดียวกับเสียงในเกม)
และอยู่ใน `MAP` ของ `build_sfx.py` เรียบร้อย ออกมาเป็น `assets/audio/sfx/ui_*.{ogg,m4a}`

โฟลเดอร์นี้เหลือไว้เป็นบันทึกว่าเคยคัดอะไรไว้บ้าง ไม่มีไฟล์แล้ว

| ชื่อในเกม | มาจาก | เอาไว้ทำ |
|---|---|---|
| `ui_click_1` / `ui_click_2` | `click2` / `click4` | กดปุ่มทั่วไป |
| `ui_hover` | `rollover2` | เลื่อนผ่านปุ่ม (เดสก์ท็อปเท่านั้น) |
| `ui_pick_1` / `ui_pick_2` | `select_001` / `select_002` | เลือกตัวละคร |
| `ui_back` | `back_002` | ย้อนกลับ — ต่ำกว่าเสียงเลือก = ทิศทางตรงข้าม |
| `ui_start` | `confirmation_001` | กดเริ่มเกม |

โค้ดอยู่ที่ `src/ui/uisfx.js` · เทสต์อยู่ที่ `tools/tests/ui_sfx.test.mjs`
ทั้งสามเรื่องที่เคยเขียนเตือนไว้ (นโยบาย autoplay · ปุ่มปิดเสียง · พังแล้วไม่ลาม) มีเทสต์คุมแล้ว
