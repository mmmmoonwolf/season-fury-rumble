# EYE — สายบู๊ "หมัดมาช้ากว่าเสียง" (✅ **กลไกเข้าเกมแล้ว** · อาร์ตยังไม่มี วาดเป็นกล่อง)

ตัวละครที่ยังอยู่ในคิว · ผู้หญิง ถือใบกัญชา · ธีม "เล่นกับเวลา"
โจทย์จากผู้เล่น: **ขอฮา ๆ ไว้แกล้งคนเล่น · ขอคอมโบได้หลายแบบ · ขออารมณ์บอสประจำแมพ**
และรอบนี้เพิ่ม: **ขอบู๊ ๆ** — จากที่เล่นกันจริงแล้วเห็นว่าตัวที่ต่อยเตะรัว ๆ ได้เปรียบ

| BOMB | 1/3 | 5 |
| OAT | 0/3 | 5 |
| TEEMEE | 0/3 | 4 |

คนที่ตีไม้เดียวต้องชนะการอ่านเกมทุกครั้งถึงจะได้แต้ม คนที่ตีห้าไม้พลาดได้แล้วยังกดต่อ

> (`max(0.5, 1 − 0.08 × comboHits)`) สิ่งที่มันวัดได้ตรง ๆ คือ **แรงกดดันต่อการกดหนึ่งครั้ง**

## แนวใหม่ (สายบู๊) — "หมัดมาช้ากว่าเสียง"

> **ทุกอย่างที่เธอทำ เกิดสองครั้ง — ครั้งแรกตอนนี้ ครั้งที่สองอีกสักพัก**

เธอเมา หมัดเลยมาถึงทีหลัง · เธอไม่ได้วางกับดักรอ เธอ**เข้าไปต่อย**
แต่หมัดที่ต่อยไปแล้วยังไม่จบ มันค้างอยู่ในอากาศแล้วค่อยระเบิดตามทีหลัง

### สามสกิล

| สกิล | กดแล้วเกิดอะไรทันที | แล้วอะไรตามมาทีหลัง |
|---|---|---|
| **1 · รัวควัน** | ตบใบกัญชารัวแบบกดรัวยืดได้ (โครงเดียวกับ Hundred Hands) | ทุกไม้ที่ 2 ทิ้ง "ควันค้าง" ไว้ตรงนั้น ระเบิดอีก 20 เฟรมให้หลัง |
| **2 · ต่อยแล้วย้อน** | พุ่งเข้าไปต่อยหนักหนึ่งไม้ | จบท่าแล้ว **เธอเด้งกลับไปยืนที่เดิม** ที่ยืนก่อนกด |
| **3 · ม่านควัน** (อัลติ) | ระเบิดควันรอบตัว ดันทุกคนออก | ~5 วิ **ทุกหมัดของทุกคนบนเวทีมีควันตาม** รวมหมัดที่ตีเธอ |

### ทำไมถึงบู๊จริง ไม่ใช่บู๊แค่ชื่อ

สกิล 1 คือหมัดรัวตรง ๆ แบบที่คุณเห็นว่าได้เปรียบ — แต่มีอีกชั้น:
**เธอหยุดรัวแล้วแรงกดดันยังไม่หยุด** เพราะควันที่ทิ้งไว้ยังทยอยระเบิด
คนที่กันอยู่จะปล่อยการ์ดตอนเห็นเธอหยุด ซึ่งคือจังหวะที่ควันลง

สกิล 2 มีดาเมจตั้งแต่เฟรมแรก ไม่ใช่ท่าเปล่า — **การย้อนกลับเป็นราคาที่จ่ายทีหลัง ไม่ใช่สิ่งที่ซื้อก่อน**
(กติกาจากบทเรียน KUNJAE: ห้ามมีสกิลที่ "ทำอะไรที่ไม่ใช่ดาเมจก่อน แล้วค่อยแปลงทีหลัง")

### คอมโบหลายแบบมาจากไหน (รอบนี้มาจากจังหวะ ไม่ใช่ตำแหน่ง)

ร่างเก่าให้คอมโบหลายแบบด้วย "เขาอยู่เขตไหน" รอบนี้เปลี่ยนเป็น **"ควันจะลงตอนไหน"**
ซึ่งเป็นของที่คนเล่นคุมเองได้ทุกครั้งที่กด ไม่ต้องรอให้เขาเดินไปยืนถูกที่

```
รัวยาว ๆ ไม่หยุด        -> ควันลงทับหมัดจริง = ไม้ถี่ขึ้น ดันเขาเข้ามุมเร็ว
รัวสั้นแล้วถอย          -> ควันลงตอนเขาเพิ่งปล่อยการ์ด = เปิดคอมโบใหม่ฟรี
รัว -> สกิล 2 -> ย้อน   -> เธอกลับมายืนที่เดิม แต่ควันยังลงอยู่ตรงนั้น = ตีสองที่พร้อมกัน
ควันลงตอนเขาลอย         -> เด้งค้างกลางอากาศ ต่อลอยได้
กดสกิล 2 กลางคอมโบ      -> ย้อนกลับไปที่ระยะเดิม = เริ่มคอมโบเดิมซ้ำได้อีกรอบ
```

**บรรทัดสุดท้ายคือหัวใจ** — สกิล 2 คืนระยะให้เธอ แปลว่าคอมโบของเธอ *วนกลับมาที่เดิมได้*
ตัวอื่นคอมโบเป็นเส้นตรง (MARCH ชุดตายตัว · KUNJAE บันไดเรียง) **ของเธอเป็นวง**

### มุกที่ทำให้เป็น "ของกลาง" ไม่ใช่ "ของเธอ" (เก็บจากร่างเก่า)

อัลติไม่ได้บัฟเธอ — **มันเปลี่ยนกติกาของทุกคน** หมัดของคู่ต่อสู้ก็มีควันตามด้วย
คนที่ตีเธอตอนม่านควันจะโดนควันของตัวเองซ้ำถ้ายืนผิดที่ · เล่น 4 คนคือความวุ่นวายสูงสุดของเกม

อันนี้คือ *"จะช่วยหรือจะแย่ง"* — เหตุผลที่บอสประจำแมพสนุก — ยัดเข้ามาในตัวละครได้โดยไม่ต้องมีบอสจริง

### เข้าเกมแล้ว — เล่นได้จริง (v17)

`id` = **`chronos`** (ชื่อในตำนาน ตามกติกาเดิมของโรสเตอร์ · ธีมเวลาพอดี) · `label` = EYE
**เปลี่ยน `id` ไม่ได้อีกแล้ว** มันคือคีย์ของอัตลาส ชื่อไฟล์ชีต และค่าที่ส่งข้ามเน็ต

| ของ | อยู่ที่ไหน |
|---|---|
| ท่าและสกิล | `EYE_MOVES` ใน `core.js` |
| ควันค้าง | `spawnPuff()` + `updatePuffs()` · ค่าอยู่ที่ `PUFF_DELAY` / `PUFF_DMG` / `PUFF_HALF` |
| ม่านควัน | `this.haze` (สถานะของ**เวที** ไม่ใช่ของเธอ) ใส่ควันให้ทุกคนใน `resolveHit` |
| ย้อนกลับ | `m.rewind` — จำ x ตอนเริ่มท่า เด้งกลับตอนจบ |
| เอฟเฟกต์ควัน | `SMOKE` + ตัววาด `puffDrop` `puffPop` `hazeOn` `rewind` `drag` |
| ควันตามไม้ | `_smokeFor()` เรียกจาก `_attackSmoke()` — **ทุกท่าที่มีกรอบชน** |
| ควันประกอบ | `_hazeAmbient()` (ตอนม่านควัน) · `_jointSmoke()` (ตอนยืน/ย่อ/วิ่ง) |

### ควันตามไม้ — ทุกท่า ไม่ใช่เฉพาะสกิล

อยู่ฝั่งวาดล้วน ๆ ไม่ต้องเติมอะไรลงตารางท่า **ท่าไหนมีกรอบชน ท่านั้นมีควัน**
ครอบคลุมท่าที่เพิ่มทีหลังเองอัตโนมัติ · ทรงควันเลือกจาก**สัดส่วนกรอบ** ไม่ใช่จากรายชื่อท่า:

| กรอบ | ควัน |
|---|---|
| สูงกว่ากว้าง 1.3 เท่า (`up` `nair`) | เสาควันพุ่งขึ้น |
| กว้างกว่าสูง 2 เท่า (`down` `side`) | ควันเลื้อยไปกับพื้น |
| ที่เหลือ | ก้อนควันตามหมัด |
| พื้นที่เกิน 6000 | เพิ่มจำนวนก้อน + ควันลงพื้น |

**ขนาดยึดกรอบชนจริง** (`hb.w / 350`) เหมือนรอยฟาด — ควันที่ใหญ่กว่าที่กินจริงคือการโกหกระยะ

🔴 **สองอย่างที่พลาดตอนทำ เห็นก็ต่อเมื่อเปิดดูของจริง:**
1. ครั้งแรกแขวนทริกเกอร์ไว้ในทางวาดสไปรท์ (ข้าง `slashFor`) แล้ว **ควันไม่เคยออกสักครั้ง**
   เพราะทางนั้น**คืนค่าออกก่อน**สำหรับตัวที่ยัง `artPending` — เทสต์เขียวหมด
   (ผลข้างเคียงที่ยังไม่แก้: ตัวที่ยังไม่มีอาร์ตก็ไม่มีรอยฟาดด้วย — ของเดิม ไม่ใช่ของใหม่)
2. หารสเกลผิดฐาน ได้ก้อนละ 35 px ซึ่งบนจอแทบมองไม่เห็น — `smokeBall` กว้าง 266 px
   ในอัตลาส ต้องหารด้วย ~350 ไม่ใช่ 900

**หน้าตาเคาะแล้ว** — `art_reference/chronos_sheets/REF_joint.jpg`
สาวผมดำมัดจุกปล่อยปอยยาว ตาปรือครึ่งหลับ ชุดดำล้วนทรงหลวม **เท้าเปล่า** **คาบมวนที่จุดแล้ว**
มือที่ว่างคือมือที่เธอใช้ต่อย — ไม่มีอาวุธ (ร่างก่อนหน้าให้ถือใบกัญชายักษ์ฟาด ตัดทิ้งแล้ว)
วัดแล้วความสว่าง 40% ล่าง = 38 เข้มที่สุดในโรสเตอร์ · prompt ทั้งชุดอยู่ที่ `art_prompts_eye.md`

🔴 **ควันในเรฟเป็นก้อนแยกจากตัว** (3,263 px ไม่ติดตัวเลย) ตัวตัดชีตจะลบทิ้งหรือนับเป็นท่าหนึ่งท่า
→ **มวนเอามาได้ ควันห้ามเอามา** เกมพ่นให้เองด้วย `_jointSmoke()` ซึ่งดีกว่าเพราะมันขยับ
และไม่พังตอนเธอตีลังกากลางอากาศ

### gimmick: สูบหนึ่งที (`hazeEnd` มี `drag`)

ไม้จบของชุดรัว **เร่งควันของเธอที่ค้างอยู่ให้ลงพร้อมกันเดี๋ยวนี้** ไม่ต้องรอครบฟิวส์
ยิ่งรัวนานยิ่งมีควันค้างเยอะ ยิ่งจบแล้วลงหนัก (วัดแล้ว: ไม่รัว 1 ก้อน · รัวเต็มแม็ก 2 ก้อน)
ควันของชุดรัวจึงมีฟิวส์ยาวกว่าปกติ (`PUFF_FUSE_FLURRY` 48 เทียบ `PUFF_DELAY` 20) เพราะมันรอไม้จบ

**ไม่ใช้ปุ่มใหม่** — ปุ่มในเกมเต็มแล้ว และเพิ่มปุ่มแปลว่าต้องแก้รูปแบบสายข้อมูลของ netplay
(`HELD`/`PRESSED` ใน `netplay.js`) ซึ่งทำให้แท็บที่เปิดค้างเล่นกับแท็บใหม่ไม่ได้ทันที

🔴 **บทเรียนที่เจอตอนทำ: `at:` ของ move property ต้องอยู่ในช่วงเงื้อ ไม่ใช่ช่วงที่กรอบชนเปิด**
ตอนไม้เข้าเป้า **คนตีก็ติด hitstop ด้วย** แล้ว `advanceMove` ถูก `continue` ข้ามทั้งบล็อก
`moveF` จึงค้างอยู่ที่เลขเดิมหลายเฟรมแล้วท่าจบไปเลย — ตั้ง `at: 8` กับ `startup: 6`
แล้วโค้ดบรรทัดนั้น**ไม่เคยทำงานสักครั้ง** (วัดแล้ว: moveF ค้างที่ 6 อยู่ 12 เฟรมติด)
ใครจะเพิ่ม `at:` อะไรใหม่ต่อจากนี้ ให้ตั้งในช่วง startup เสมอ

**อาร์ตยังไม่เจน** — ติด `artPending: true` วาดเป็นกล่องเขียวไปก่อน (ท่าเดียวกับที่ TEEMEE เคยใช้)
ลบธงนี้ทั้งใน `core.js` และ `ScrambleScene.js` แล้วเติม `atlasKey`/`texture`/`data`/`anims`/`attacks` ตอนอาร์ตมาถึง

### สิ่งที่เรียนรู้ตอนทำควันให้มองเห็นจริง

1. **ควันต้องเป็น NORMAL เสมอ ห้าม ADD** — รู้อยู่แล้วจากหมัดรัวของ MARCH แต่ยังไม่พอ
2. **ชั้นเดียวไม่พอ** ต้องเป็นก้อนทึบสีเข้มข้างหลัง + ขอบสว่างบาง ๆ ข้างหน้า
3. **วงแหวนกับแสงกลบควันได้** — รอบแรกตั้งวงแหวนไว้สว่าง ผลคือบนจออ่านเป็น
   "วงแหวนเขียว" ไม่ใช่ควัน ต้องหรี่วงแหวนลงจนควันเป็นตัวเอก
4. **ขนาดก้อนทึบต้องตรงกับระยะที่มันตีจริง** รอบแรกกว้าง ~200 px ขณะที่ `PUFF_HALF` = 58
   (กว้างจริง 116) = โกหกระยะ 1.7 เท่า แล้วคนเล่นจะเรียนรู้ระยะจากควันที่โกหก
   ควันที่ฟุ้งเลยระยะยังมีได้ แต่ต้องบางและจางให้ตาแยกออก
5. **สีเข้มสนิทไม่ใช่ควัน** ม่านควันตั้งไว้ `0x312a40` แล้วอ่านเป็นแท่งดำพาดเวที
   ต้องมีไล่น้ำหนักในตัวมันเอง (`0x544868`)

กติกาไม่โดนพวกเดียวกัน และคูณดาเมจตาม `comboHits` อยู่แล้ว
ควันค้างคือของแบบเดียวกันแต่ **ระเบิดครั้งเดียวตอนหมดเวลา** แทนที่จะตอดเป็นช่วง

### สิ่งที่ต้องทำใหม่จริง ๆ
1. **หน่วงก่อนออกฤทธิ์** — ของที่มีตอนนี้ออกฤทธิ์ทันทีที่วาง ต้องเพิ่มตัวนับถอยหลังก่อนตื่น
2. **จำตำแหน่งเดิม** (สกิล 2) — เก็บ x ตอนเริ่มท่า แล้วเด้งกลับตอนจบ · ไม่ต้องเก็บประวัติยาว

ทั้งสองอย่างเป็นตัวนับเฟรมล้วน ๆ **ยังเป็น lockstep เหมือนเดิม เล่นข้ามเครื่องไม่พัง**

### ข้อดีของแนวนี้เทียบกับร่างเก่า
ร่างเก่าต้องทำ **ตัวคูณความเร็วรายคน** ซึ่งเอนจิ้นยังไม่มีเลย และแตะทุกอย่างที่เดินตามเฟรม
(ฟิสิกส์ ท่า คูลดาวน์ hitstun) — เสี่ยงที่สุดในบรรดาของที่เคยเพิ่มเข้าเกม
แนวนี้ไม่ต้องแตะนาฬิกากลางเลยสักจุด

## กติกาที่ยึดไว้ (บทเรียนจาก KUNJAE)

ห้ามเป็นโครง *"ทำอะไรที่ไม่ใช่ดาเมจก่อน แล้วค่อยแปลงทีหลัง"*
สามรอบที่พังของ KUNJAE เป็นโครงนี้หมด และตัวละคร "เล่นกับเวลา" เอียงไปทางนี้โดยธรรมชาติมาก
**ทุกสกิลต้องมีผลที่รู้สึกได้ทันทีที่กด**

### แยกการแกล้งเป็นสองชั้น

| ชั้น | คืออะไร | ต้นทุนสมดุล |

ชั้นแรกฟรี เพราะเอนจิ้นแยกซิมกับฝั่งวาดขาดกันอยู่แล้ว — หลอดเลือดสั่น เลขดาเมจมั่ว

## ร่างแรก (สายวางเขตเวลา) — เก็บไว้ ยังไม่ทิ้ง

ร่างนี้ให้คอมโบหลายแบบด้วย **ตำแหน่ง** (เขาอยู่เขตไหน) แทนที่จะเป็นจังหวะ
ลึกกว่าในแง่การวางแผน แต่ **ไม่บู๊** — เธอวางของทิ้งไว้แล้วรอ ซึ่งสวนกับโจทย์รอบนี้
เก็บไว้เพราะมุก "เขตไม่เว้นใครรวมทั้งเธอเอง" ยังดี และถูกยกไปใช้ในอัลติของแนวใหม่แล้ว

<summary>กางดูร่างเต็ม</summary>

### "เวทีคือนาฬิกาของเธอ"

> **เธอไม่ได้ร่ายสกิลใส่คู่ต่อสู้ — เธอวางเขตเวลาทิ้งไว้บนแมพ
> แล้วเวทีก็ไม่ใช่เวทีเดิมอีกต่อไป**

สามสกิลคือ **ควันสามก้อนที่พ่นทิ้งไว้กับพื้น** ไม่ใช่ท่าตี

| เขต | ในเขตเกิดอะไร | เป็นเครื่องมือคอมโบยังไง |
|---|---|---|
| **ยืด** | ทุกอย่างช้าลง 0.6x — ตกช้า เซช้า | ตบเข้าไปแล้วเขาค้างกลางอากาศ = ต่อคอมโบลอยยาว |
| **หด** | ทุกอย่างเร็วขึ้น 1.5x · แรงกระเด็นคูณเพิ่ม | ดีดเขาข้ามจอเข้ามุม แล้วเด้งกำแพง |
| **หยุด** | เขตเล็ก ใครแตะค้าง ~25 เฟรม | รีเซ็ตคอมโบ · ข้ามไปหลัง · หรือใช้หนีเอาตัวรอด |

**อัลติ "ม่านควัน"** — สามเขตรวมร่างกลืนทั้งแมพ ~5 วินาที ทั้งเวทีเดินตามนาฬิกาเธอ
คนอื่นช้าหมด เธอคนเดียวปกติ · จอเปลี่ยนเกรดสีเป็นม่วง-เขียว ฉากหลังหยุดไหล เลขเวลาบนจอรวน

#### มุกที่ทำให้เป็น "ของกลาง" ไม่ใช่ "ของเธอ"

> **เขตของเธอไม่เว้นให้ใคร — ใครเหยียบก็ได้ผล รวมทั้งตัวเธอเอง**

คู่ต่อสู้ที่ฉลาดจะยืนในเขต "หด" ของเธอเพื่อกดดันกลับ · เธอเผลอถอยเข้าเขต "ยืด"
ตัวเอง = ค้างเป็นเป้านิ่ง · เล่น 4 คน เขตก้อนเดียวเปลี่ยนเกมทั้งวง

อันนี้คือ *"จะช่วยหรือจะแย่ง"* — ประโยคที่เขียนไว้ในหัวไฟล์ `BossSystem` ของโหมดเก่า
ซึ่งเป็นเหตุผลที่บอสประจำแมพสนุก — ยัดเข้ามาอยู่ในตัวละครได้โดยไม่ต้องมีบอสจริง

#### คอมโบหลายแบบมาจากไหน

ไม่ได้มาจากจำนวนท่า แต่มาจาก **ตีโดนไม้เดียวกัน แต่เขาอยู่คนละเขต = คนละคอมโบ**

```
ตบเข้าเขตยืด   -> เขาลอยค้าง -> ไล่ต่อบนอากาศยาว ๆ
ตบเข้าเขตหด    -> เขาดีดไกล  -> วิ่งตาม -> เด้งกำแพง -> รับต่อ
ตบเข้าเขตหยุด  -> เขาค้าง    -> เธอเดินข้ามไปหลัง -> เปิดใหม่อีกฝั่ง
วางเขตกลางคอมโบ (ยกเลิกท่าเข้าเขต) -> เปลี่ยนทางกลางคันทั้งที่คอมโบยังไม่ขาด
เขตซ้อนกันสองก้อน -> ยืด+หด หักล้างกัน = ช่องว่างที่ทั้งคู่ต้องอ่านเอง
```

เธอจึงเป็น **"สายเลือกทาง"** ซึ่งเป็นช่องที่ยังว่างในโรสเตอร์
(MARCH = ชุดตายตัว · KUNJAE = บันไดเรียงตายตัว · ยังไม่มีใครเล่นกับตำแหน่ง)

## แนวอื่นที่คิดไว้ (ยังไม่ทิ้ง)

- **"เงาเวลา"** — สกิลทิ้งเงาของเธอไว้ เงาเล่นท่านั้นซ้ำอีก 30 เฟรมให้หลัง = คอมโบสองชั้น
  ลึกที่สุดแต่งานเยอะที่สุด · **ใกล้กับแนวใหม่มาก** ต่างกันตรงเงาเล่น *ท่าเต็ม* ส่วนควันระเบิดเฉย ๆ
  ถ้าแนวใหม่ผ่านแล้วอยากได้ลึกกว่านี้ อันนี้คือขั้นถัดไป ไม่ใช่ทางแยก
- **"ยกเลิกได้สามทาง"** — ท่าไหนก็กดสกิลแทรกกลางท่าได้ สามสกิลคือการยกเลิกสามชนิด
- **"หาย"** — ถอยหลังแล้วหายไป 6 เฟรม ("ลืมว่าตัวเองอยู่ตรงไหน") เอาไปเป็นท่าถอยได้เลย

> **"ดีเลย์" ไม่ได้อยู่ในลิสต์นี้แล้ว** — มันถูกยกขึ้นไปเป็นแกนของแนวใหม่
