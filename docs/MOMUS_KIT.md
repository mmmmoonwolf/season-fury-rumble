# MOMUS — ผังสกิลที่ล็อกแล้ว (ยังไม่เขียนโค้ด · ตั้งใจทำเป็นตัวสุดท้าย)

**The Fury of the Last Laugh** · สายป่วนสนาม · ตัวตลกผมส้มหยิกในชุดขาดวิ่น

ชื่อมาจาก **เทพแห่งการเยาะเย้ย** ในตำนานกรีก — เทพที่เอาแต่หัวเราะเยาะเทพองค์อื่น
จนโดนไล่ออกจากโอลิมปัส **เทพองค์เดียวที่ถูกเนรเทศเพราะขำคนอื่นมากเกินไป**

---

## กลไกประจำตัว: ป่วนสนาม (Chaos)

**เขาไม่ได้สู้กับคุณ เขาจัดสนามใหม่ แล้วระเบิดมันทิ้ง**

สี่ตัวแรกทุกตัวมีสกิลที่เล็งใส่คู่ต่อสู้ ตัวนี้ไม่เล็งใคร — **มันโดนทุกคนที่ยืนผิดที่**

### กฎเหล็กของตัวนี้: ทุกอย่างไม่เลือกข้าง

| | |
|---|---|
| กล่องที่เขาวาง | **เขาเหยียบเองก็ระเบิดใส่ตัวเอง** |
| จังหวะสลับที่ | **ระเบิดทั้งจุดที่ไปและจุดที่มา** ใครยืนอยู่แถวนั้นก็โดน |

**เขาเป็นตัวเดียวในเกมที่สกิลตัวเองฆ่าตัวเองได้**
ไม่ได้ชนะเพราะสกิลแรงกว่า แต่ชนะเพราะ**เขารู้ว่าระเบิดจะลงตรงไหน ส่วนคนอื่นไม่รู้**

---

## ออกแบบเผื่อเล่นหลายคน (3-4 คน) มาตั้งแต่ต้น

ตัวนี้คือตัวที่ **ยิ่งคนเยอะยิ่งแรง** โดยไม่ต้องแก้อะไรเลย เพราะทุกท่าไม่เลือกเป้า

| | 1v1 | 3-4 คน |
|---|---|---|
| กล่องระเบิด | ดักได้คนเดียว อ่านง่าย | **วางกลางวงที่คนกำลังตีกัน = โดนหลายคนพร้อมกัน** |
| สลับที่ | สลับกับคู่ต่อสู้คนเดียว | **สลับกับคนที่ใกล้ที่สุด** แล้วทิ้งระเบิดไว้กลางวง |
| จุดอ่อน "คนนิ่งไม่หลงกล" | เป็นปัญหาจริง | **แทบไม่เป็นปัญหา** เพราะไม่มีใครยืนนิ่งได้ตอนมีสามคนรุมกัน |

**กติกาเลือกเป้าตอนหลายคน: เอาคนที่ใกล้ที่สุดเสมอ** — คิดจากระยะล้วน ไม่มีสุ่ม
สองเครื่องจึงคำนวณได้ตรงกันเป๊ะ ซึ่งจำเป็นสำหรับ netplay

> **ข้อเท็จจริงที่ต้องรู้:** เอนจิ้นตอนนี้รองรับแค่ 2 คน — `Game` มี `p1` กับ `p2` ตายตัว
> `foe()` คืน "อีกคน" ตรง ๆ และ lockstep ของ netplay ก็เป็นสองฝ่าย
> ทำ 3-4 คนจริง ๆ คือการรื้อใหญ่ ไม่ใช่งานเสริมเล็ก ๆ
> **แต่ผังของตัวนี้ออกแบบมาให้พร้อมแล้ว ไม่ต้องคิดใหม่ตอนรื้อ**

## ท่าปกติ — หมัดพันผ้ากับแขนเสื้อขาด ๆ

ช้าแต่**ระยะไกลกว่าที่คิด** เพราะแขนเสื้อรุ่ยยาวสะบัดออกไป

| ท่า | ทำอะไร |
|---|---|
| jab1-2-3 | เหวี่ยงหมัดหนัก ๆ สามจังหวะ ช้าแต่วงกว้าง |
| side | พุ่งสะบัดแขนเสื้อไปข้างหน้า **มีแรงส่งตัวตามไปด้วย** — ทางเข้าหลักของเขา |
| up | หมัดเสยขึ้น **ทำให้ลอย** (ป้อนวงจรลูกโป่ง) |
| down | กวาดขาต่ำ |
| nair / sair / dair | เหวี่ยงกลางอากาศ |

## สกิล

### 1 · Jack-in-the-Box (กล่องระเบิด) — วางระเบิดเวลาลงบนพื้น

วางกล่องทิ้งไว้บนพื้น **วางพร้อมกันได้ 2 กล่อง**

| | |
|---|---|
| ระเบิดเมื่อไหร่ | **ใครเหยียบ** หรือ **ครบ 5 วินาที** อย่างใดถึงก่อน |
| ระเบิดยังไง | ตุ๊กตาเด้งพรวด **ดาเมจปานกลาง + ดีดลอยขึ้น** รัศมีรอบกล่อง |
| โดนใคร | **ทุกคนในรัศมี รวมตัวเขาเอง** |

ระเบิดเองเมื่อครบเวลา = ต่อให้ไม่มีใครเหยียบก็ยังเป็นระเบิด ไม่ใช่กับดักที่เสียเปล่า
**สองกล่องวางคนละที่ = บังคับให้ทุกคนต้องเลือกว่าจะยืนตรงไหน**

### 2 · Ta-da! (สลับที่) — ระเบิดสองจุดพร้อมสลับตำแหน่ง

โค้งคำนับ แล้ว **สลับที่กับคนที่ใกล้ที่สุด** — และ **ระเบิดขึ้นทั้งสองจุด**

| | |
|---|---|
| ดาเมจ | เบากว่ากล่อง แต่โดน **สองจุดพร้อมกัน** |
| โดนใคร | ทุกคนที่ยืนใกล้จุดใดจุดหนึ่ง **รวมตัวเขาเอง** |
| ผลพ่วง | ลบระยะที่อีกฝ่ายจัดมาทั้งยก |

- อีกฝ่ายถอยไปตั้งหลักมุมจอ → **เขาไปแทน แล้วดันคนนั้นมากลางเวที พร้อมระเบิดสองลูก**
- ตัวเองโดนต้อนติดมุม → **สลับออกมาได้ พร้อมทิ้งระเบิดไว้ให้คนที่ไล่**
- **ต่อกับสกิล 1:** วางกล่องไว้ แล้วสลับให้อีกฝ่ายไปโผล่ทับกล่องพอดี

> ต่างจากวาร์ปของ Nyx: ของ Nyx ย้ายตัวเองไปเพื่อจะฟัน
> **ของนี้ย้ายอีกฝ่ายด้วย และระเบิดทิ้งไว้ทั้งสองที่**

### 3 · อัลติ — มีสามแบบให้เลือก (ยังไม่ล็อก)

ดูหัวข้อ "สามทางเลือกของอัลติ" ข้างล่าง

---

## สามทางเลือกของอัลติ

### แบบ A · Last Laugh (ยัดกล่อง) — ของเดิม

คว้าตัวยัดใส่กล่อง ปิดฝา นั่งทับ แล้วกล่องระเบิด · กันไม่ได้ · **ดาเมจสูงสุดในเกม**

| ข้อดี | ข้อเสีย |
|---|---|
| ภาพจำแรงที่สุด เป็นมุกของตัวละครเลย | **โดนคนเดียว** — เล่น 4 คนแล้วอ่อนที่สุด |
| เป็นปุ่มเดียวที่ทำดาเมจก้อนใหญ่ | ระยะสั้นมาก พลาดแล้วแพ้ยกนั้น |

### แบบ B · Full House (โปรยกล่องทั้งเวที) — **ผมแนะนำอันนี้**

โยนกล่องกำมือหนึ่งขึ้นฟ้า **กล่องตกกระจายทั่วเวที** แล้ว**ระเบิดไล่กันเป็นทอด ๆ**

| ข้อดี | ข้อเสีย |
|---|---|
| **ทุกคนบนแผนที่ต้องวิ่ง** ไม่มีที่ปลอดภัย | ไม่มีภาพ "จับใส่กล่อง" ที่เป็นมุกประจำตัว |
| **ยิ่งคนเยอะยิ่งแรง** ตรงตัวที่สุด | ดาเมจต่อคนน้อยกว่าแบบ A |
| เป็นอัลติที่ขยายจากสกิล 1 ของตัวเอง | |
| **เขาก็โดนเอง** ตรงกฎเหล็ก | |

### แบบ C · Encore of Errors (สลับทุกคน)

**ทุกคนบนแผนที่ถูกสลับตำแหน่งพร้อมกัน** (เลื่อนไปคนละหนึ่งตำแหน่ง ไม่ใช่สุ่ม)
แล้วระเบิดขึ้นทุกจุดที่มีคนยืน

| ข้อดี | ข้อเสีย |
|---|---|
| ตลกที่สุด และป่วนที่สุดเมื่อเล่น 4 คน | **เล่น 1v1 แล้วเหมือนสกิล 2 ทุกอย่าง** |
| ไม่มีสุ่ม สองเครื่องคำนวณตรงกันได้ | อ่านยากมาก อาจงงมากกว่าสนุก |

> **ข้อเสนอ:** เอา **B** เป็นอัลติ แล้วย้ายภาพ "ยัดกล่อง" ไปเป็น**ไม้จบของท่าตีปกติ**
> (ตีครบชุดแล้วจบด้วยยัดกล่อง) จะได้ทั้งมุกประจำตัวและอัลติที่เล่นหลายคนได้

## จุดอ่อนที่ตั้งใจให้มี

**ดาเมจของเขาไม่มีอะไรรับประกันเลย** — ระเบิดทุกลูกหลบได้ถ้าเห็นทัน
ตัวอื่นกดปุ่มแล้วดาเมจออกแน่ ๆ ของเขาต้องหลอกให้คนเดินไปยืนผิดที่ก่อน

**ไม่มีท่ายิง** ตัวเดียวในโรสเตอร์ที่ไม่มีอะไรออกไปไกลได้

**สกิลตัวเองฆ่าตัวเองได้** เหยียบกล่องตัวเองตอนกำลังหนีคือจบ
สลับที่แล้วไปโผล่กลางวงคอมโบก็มี — เล่นตัวนี้คือเล่นกับไฟ

**เล่น 1v1 กับคนที่นิ่งและไม่หลงกล เขาอ่อนที่สุดในเกม** — ความวุ่นวายต้องมีคนวุ่นด้วย
(แต่พอเล่น 3-4 คน ข้อเสียนี้แทบหายไป เพราะไม่มีใครยืนนิ่งได้ตอนโดนรุม)

## ข้อควรรู้ตอนลงมือเขียน

1. **กล่องระเบิดใช้ระบบกองไฟของ Alecto ได้เลย** (`spawnFire` / `updateFires`)
   ของเดิมตอดดาเมจเรื่อย ๆ ของนี้ระเบิดทีเดียวแล้วหาย + ดีดลอย
   **ต้องเช็กทุกคนไม่ใช่แค่ฝ่ายตรงข้าม** — ของเดิมเขียนว่า
   `fire.owner === 'p1' ? this.p2 : this.p1` ซึ่งข้ามเจ้าของไปเลย ตรงนี้ต้องแก้
   อยู่ในตัวเทียบสถานะของ netplay อยู่แล้ว ไม่ต้องเพิ่มอะไรใหม่

   **นับเวลาถอยหลังด้วยเลขเฟรมล้วน** ห้ามผูกกับเวลาจริง ไม่งั้นสองเครื่องหลุดกัน

2. **สลับที่ต้องสลับ `x` อย่างเดียว ห้ามแตะ `y` / `vx` / `vy`**
   ถ้าสลับความเร็วด้วยจะเกิดอาการกระตุกและคาดเดาไม่ได้
   และต้อง **บีบให้อยู่ในกำแพงเวที** หลังสลับ (เหมือน `warp` ของ Nyx ทำอยู่)

3. **สลับที่ต้องไม่ทำงานตอนอีกฝ่ายมี `invuln`** ไม่งั้นลากคนที่กำลังล้มได้ = พัง

4. **ท่าจับของอัลติกันไม่ได้ = ของใหม่ในเอนจิ้น** ตอนนี้ทุกอย่างบล็อกได้หมด
   ต้องเพิ่มธง `unblockable` ให้ `resolveHit` ข้ามเช็กบล็อก แต่ยังเช็ก `invuln` อยู่

5. **`kb[1]` ของ jab1-2 ต้องเป็น 0** ถีบขึ้นแม้นิดเดียวคู่ต่อสู้จะลอย
   พอตกถึงพื้นกลายเป็นท่าล้มซึ่งมี invuln ติดมา จังหวะที่เหลือจะฟาดลม
   — กับดักนี้กัดมาแล้วสี่รอบ · ท่า `up` ที่ตั้งใจให้ลอยไม่นับ เพราะจบคอมโบตรงนั้นพอดี

6. **ห้ามตั้ง `active: 0`** `phase()` จะข้ามช่วง active ทั้งช่วง เฟรมอาร์ตกลางไม่ถูกวาด

7. **ท่าจับต้องมีเฟรม "คว้าไม่โดน" แยก** ไม่งั้นพลาดแล้วจะดูเหมือนจับติด
