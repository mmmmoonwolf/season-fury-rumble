# MOMUS — ผังสกิลที่ล็อกแล้ว (ยังไม่เขียนโค้ด · ตั้งใจทำเป็นตัวสุดท้าย)

**The Fury of the Last Laugh** · สายป่วนสนาม · ตัวตลกผมส้มหยิกในชุดขาดวิ่น

ชื่อมาจาก **เทพแห่งการเยาะเย้ย** ในตำนานกรีก — เทพที่เอาแต่หัวเราะเยาะเทพองค์อื่น
จนโดนไล่ออกจากโอลิมปัส **เทพองค์เดียวที่ถูกเนรเทศเพราะขำคนอื่นมากเกินไป**

---

## กลไกประจำตัว: ป่วนสนาม (Chaos)

**เขาไม่ได้สู้กับคุณ เขาจัดสนามใหม่**

สี่ตัวแรกทุกตัวมีสกิลที่ "ทำอะไรใส่คู่ต่อสู้" ตัวนี้ไม่ใช่ —
สกิลของเขา**เปลี่ยนสนาม** แล้วปล่อยให้ทั้งสองคนไปหาทางเอาเอง

### กฎเหล็กของตัวนี้: ทุกอย่างโดนทั้งสองฝั่ง

| | |
|---|---|
| กล่องสปริงที่เขาวาง | **เขาเหยียบเองก็เด้ง** |
| สลับที่ | **เขาก็โดนย้ายด้วย** อาจย้ายไปที่แย่กว่าเดิม |

**เขาเป็นตัวเดียวในเกมที่สกิลตัวเองฆ่าตัวเองได้**
เขาไม่ได้ชนะเพราะสกิลแรงกว่า แต่ชนะเพราะ**เขารู้ว่าความวุ่นวายจะเกิดตรงไหน
ส่วนอีกฝ่ายไม่รู้** — คนที่วางกับดักย่อมจำได้ว่าวางไว้ตรงไหน

> นี่คือเหตุผลที่ควรเป็น**ตัวสุดท้าย**: กว่าจะสนุกกับตัวนี้ได้
> ต้องรู้จักเวทีและรู้จักอีกสี่ตัวมาก่อน เป็นตัวสำหรับคนที่เล่นจนคล่องแล้ว

## ท่าปกติ — หมัดพันผ้ากับแขนเสื้อขาด ๆ

ช้าแต่**ระยะไกลกว่าที่คิด** เพราะแขนเสื้อรุ่ยยาวสะบัดออกไป

| ท่า | ทำอะไร |
|---|---|
| jab1-2-3 | เหวี่ยงหมัดหนัก ๆ สามจังหวะ ช้าแต่วงกว้าง |
| side | พุ่งสะบัดแขนเสื้อไปข้างหน้า **มีแรงส่งตัวตามไปด้วย** — ทางเข้าหลักของเขา |
| up | หมัดเสยขึ้น **ทำให้ลอย** (ป้อนวงจรลูกโป่ง) |
| down | กวาดขาต่ำ |
| nair / sair / dair | เหวี่ยงกลางอากาศ |

## สกิล

### 1 · Jack-in-the-Box (กล่องผี) — วางกับดักลงบนพื้น

วางกล่องสปริงทิ้งไว้บนพื้น **อยู่ 8 วินาที** · วางพร้อมกันได้ 2 กล่อง

**ใครเหยียบก็เด้งลอยขึ้นฟ้า** — ไม่มีดาเมจ ไม่เลือกข้าง **เขาเหยียบเองก็เด้ง**

นี่ไม่ใช่กระสุนและไม่ใช่กองไฟ **มันคือพื้นที่เปลี่ยนไปแล้ว**
เวทีตรงนั้นไม่ใช่พื้นราบอีกต่อไป ทั้งสองคนต้องจำและเล่นรอบมัน

| ใช้ยังไง | |
|---|---|
| ตั้งรับ | วางไว้หน้าตัวเอง คนจะเข้ามาต้องเด้งขึ้นก่อน = อ่านง่าย |
| บุก | วางไว้หลังคู่ต่อสู้ แล้วไล่ต้อนให้ถอยไปเหยียบ |
| หนี | เหยียบเองเพื่อขึ้นไปสูงกว่าที่กระโดดปกติได้ |

### 2 · Ta-da! (สลับที่) — จัดตำแหน่งใหม่ทั้งสองคน

โค้งคำนับ แล้ว **ตัวเขากับคู่ต่อสู้สลับที่กันทันที**

ท่าที่ป่วนที่สุดในเกม เพราะมันลบ "ระยะ" ที่อีกฝ่ายอุตส่าห์จัดมาทั้งยก:

- อีกฝ่ายถอยไปตั้งหลักมุมจอ → **เขาส่งตัวเองไปแทน แล้วดันคนนั้นมากลางเวที**
- อีกฝ่ายกระโดดขึ้นแท่นเพื่อหนี → **สลับแล้วคนนั้นตกลงมา ส่วนเขาได้ที่สูง**
- ตัวเองโดนต้อนติดมุม → **สลับออกมาได้ฟรี**
- **ต่อกับสกิล 1 ตรง ๆ:** วางกล่องไว้ตรงไหน แล้วสลับให้อีกฝ่ายไปโผล่ตรงนั้น

> ไม่ใช่วาร์ปแบบ Nyx — ของ Nyx ย้ายตัวเองไปหลังคู่ต่อสู้เพื่อจะฟัน
> ของนี้ **ย้ายอีกฝ่ายด้วย** และนั่นคือทั้งหมดของท่านี้ ไม่มีดาเมจสักหน่วย

**ออกช้า มองเห็นชัด คูลดาวน์ยาว** และ **ดาบสองคม** — สลับไปเจอที่แย่กว่าเดิมก็มี

### 3 · Last Laugh (หัวเราะทีหลัง · อัลติ)

คว้าตัวยัดใส่กล่อง ปิดฝา นั่งทับ แล้วกล่องระเบิด
**กันไม่ได้** · ดาเมจสูงสุดในเกม

| | |
|---|---|
| ช่วงเงื้อ | **มี iframes** — ชนท่าที่กำลังจะโดนแล้วสวนกลับได้ |
| ระยะ | สั้นมาก — ต้องจับให้ติดก่อน |
| พลาด | ค้างนานที่สุดในเกม แพ้ยกนั้นได้เลย |

**นี่คือปุ่มเดียวของเขาที่ทำดาเมจจริงจัง** และมันต้องเข้าประชิด
ซึ่งแปลว่าสองสกิลแรกมีไว้เพื่อ **จัดให้อีกฝ่ายมายืนผิดที่ผิดเวลา** แล้วค่อยเก็บ

กล่องสปริงเด้งคนขึ้นฟ้า → ตกลงมาขยับไม่ได้ชั่วขณะ → **นั่นคือจังหวะของอัลติ**

## จุดอ่อนที่ตั้งใจให้มี

**ทำดาเมจได้น้อยที่สุดในเกม** — สองสกิลแรกไม่มีดาเมจเลยสักหน่วย
ทั้งยกเขาต้องเก็บแต้มด้วยหมัดธรรมดาที่ออกช้า กับอัลติที่ต้องเข้าประชิด

**ไม่มีท่ายิง** ตัวเดียวในโรสเตอร์ที่ไม่มีอะไรออกไปไกลได้

**สกิลตัวเองฆ่าตัวเองได้** เหยียบกล่องตัวเองตอนกำลังหนีคือจบ
สลับที่แล้วไปโผล่กลางวงคอมโบก็มี — เล่นตัวนี้คือเล่นกับไฟ

**คนที่เล่นนิ่ง ๆ ไม่หลงกล เขาทำอะไรไม่ได้เลย** ความวุ่นวายได้ผลกับคนที่ตื่นเท่านั้น

## ข้อควรรู้ตอนลงมือเขียน

1. **กล่องสปริงใช้ระบบกองไฟของ Alecto ได้เลย** (`spawnFire` / `updateFires`)
   เปลี่ยนจาก "ตอดดาเมจ" เป็น "ตั้ง vy ให้เด้งขึ้น" และ **เช็กทั้งสองฝ่ายไม่ใช่แค่ฝ่ายตรงข้าม**
   อยู่ในตัวเทียบสถานะของ netplay อยู่แล้ว ไม่ต้องเพิ่มอะไรใหม่

2. **สลับที่ต้องสลับ `x` อย่างเดียว ห้ามแตะ `y` / `vx` / `vy`**
   ถ้าสลับความเร็วด้วยจะเกิดอาการกระตุกและคาดเดาไม่ได้
   และต้อง **บีบให้อยู่ในกำแพงเวที** หลังสลับ (เหมือน `warp` ของ Nyx ทำอยู่)

3. **สลับที่ต้องไม่ทำงานตอนอีกฝ่ายมี `invuln`** ไม่งั้นลากคนที่กำลังล้มได้ = พัง

4. **ท่าจับของอัลติกันไม่ได้ = ของใหม่ในเอนจิ้น** ตอนนี้ทุกอย่างบล็อกได้หมด
   ต้องเพิ่มธง `unblockable` ให้ `resolveHit` ข้ามเช็กบล็อก แต่ยังเช็ก `invuln` อยู่

5. **`kb[1]` ของ jab1-2 ต้องเป็น 0** ถีบขึ้นแม้นิดเดียวคู่ต่อสู้จะลอย
   พอตกถึงพื้นกลายเป็นท่าล้มซึ่งมี invuln ติดมา จังหวะที่เหลือจะฟาดลม
   — กับดักนี้กัดมาแล้วสี่รอบ · ท่า `up` ที่ตั้งใจให้ลอยไม่นับ เพราะจบคอมโบตรงนั้นพอดี

6. **ห้ามตั้ง `active: 0`** `phase()` จะข้ามช่วง active ทั้งช่วง เฟรมอาร์ตกลางไม่ถูกวาด

7. **ท่าจับต้องมีเฟรม "คว้าไม่โดน" แยก** ไม่งั้นพลาดแล้วจะดูเหมือนจับติด
