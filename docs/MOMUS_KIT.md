# MOMUS — ผังสกิลที่ล็อกแล้ว (ยังไม่เขียนโค้ด)

**The Fury of the Last Laugh** · สายจับ (grappler) · ตัวตลกผมส้มหยิกในชุดขาดวิ่น

ชื่อมาจาก **เทพแห่งการเยาะเย้ย** ในตำนานกรีก — เทพที่เอาแต่หัวเราะเยาะเทพองค์อื่น
จนโดนไล่ออกจากโอลิมปัส **เทพองค์เดียวที่ถูกเนรเทศเพราะขำคนอื่นมากเกินไป**

---

## กลไกประจำตัว: จับได้ (Grab) + ลูกโป่ง (Balloon)

### 1. เขาเป็นคนเดียวในเกมที่ "จับ" ได้

**ท่าจับกันไม่ได้** — บล็อกไว้แน่นแค่ไหนก็โดนจับ

นี่คือช่องว่างที่ใหญ่ที่สุดของโรสเตอร์ตอนนี้: **ยังไม่มีใครลงโทษคนที่ตั้งการ์ดนิ่ง ๆ ได้เลย**
Atlas ตั้งการ์ดแล้วเดินเข้ามา ไม่มีใครเปิดการ์ดเขาได้ — ตัวนี้คือคำตอบ

| ท่าจับ | ชนะอะไร | แพ้อะไร |
|---|---|---|
| จับ | **คนตั้งการ์ด** · คนยืนรอ | คนที่ตีสวนก่อน · **คนที่กระโดดหนี** |

แล้วอีกสกิลคือ**จับกลางอากาศ** ซึ่งปิดทางหนีข้อสุดท้ายพอดี

### 2. จับได้แล้วผูกลูกโป่งติดตัวไว้

จับติดทีไร เหยื่อจะมี**ลูกโป่งผูกอยู่ 5 วินาที** ระหว่างนั้น:

| | ผล |
|---|---|
| แรงโน้มถ่วง | **เหลือครึ่งเดียว** — ลอยค้างกลางอากาศนานขึ้นมาก |
| แปลว่า | ตกช้า หนีขึ้นฟ้าไม่รอด **เป็นเป้านิ่งกลางอากาศ** |
| ปลดยังไง | รอหมดเวลา หรือโดนอัลติป็อป |

**เขาเป็นตัวเดียวในเกมที่อยากให้คู่ต่อสู้ลอยอยู่** ทุกอย่างของเขาสอยคนลอยได้หมด
วงจรของเขาคือ **จับ → ลอย → เล่นกลางอากาศ → ป็อป**

> ต่างจากสโลว์ของ Alecto ที่ทำให้เดินช้า — อันนี้ไม่ได้ทำให้ช้าลง
> แต่ทำให้ **ควบคุมตัวเองกลางอากาศไม่ได้** ซึ่งเป็นคนละปัญหากันคนละแบบ

## ท่าปกติ — หมัดพันผ้ากับแขนเสื้อขาด ๆ

ช้าแต่**ระยะไกลกว่าที่คิด** เพราะแขนเสื้อรุ่ยยาวสะบัดออกไป

| ท่า | ทำอะไร |
|---|---|
| jab1-2-3 | เหวี่ยงหมัดหนัก ๆ สามจังหวะ ช้าแต่วงกว้าง |
| side | พุ่งสะบัดแขนเสื้อไปข้างหน้า **มีแรงส่งตัวตามไปด้วย** — ทางเข้าหลักของเขา |
| up | หมัดเสยขึ้น **ทำให้ลอย** (ป้อนวงจรลูกโป่ง) |
| down | กวาดขาต่ำ |
| nair / sair / dair | เหวี่ยงกลางอากาศ |

## สกิล

### 1 · Jack Grab (จับ) — ท่าจับพื้น

คว้าตัวแล้วทุ่มลงพื้น · **กันไม่ได้** · ผูกลูกโป่ง
ระยะสั้นมาก ออกช้า **พลาดแล้วค้างยาว กินคอมโบเต็ม** — เป็นการเดิมพันไม่ใช่ปุ่มกดฟรี

### 2 · Big Top (สอยลงเต็นท์) — ท่าจับอากาศ

เอื้อมคว้าคนที่ลอยอยู่ลงมาฟาดพื้น · **กันไม่ได้** · ผูกลูกโป่ง

สกิล 1 แพ้คนกระโดดหนี **อันนี้คือตัวปิดช่องนั้น** สองปุ่มนี้ทำงานเป็นคู่:
อยู่บนพื้นก็โดนจับ กระโดดหนีก็โดนสอย เหลือทางเดียวคือ**ต้องตีสวนเขาให้ได้ก่อน**

### 3 · Last Laugh (หัวเราะทีหลัง · อัลติ)

คว้าตัวยัดใส่กล่อง ปิดฝา นั่งทับ แล้วกล่องระเบิด · **กันไม่ได้** · ดาเมจสูงสุดในเกม

| | |
|---|---|
| ช่วงเงื้อ | **มี iframes** — ชนท่าที่กำลังจะโดนแล้วสวนกลับได้ |
| ถ้าเหยื่อมีลูกโป่งอยู่ | **แรงขึ้น** — รางวัลของคนที่เล่นตามแผนมาทั้งเกม |
| พลาด | ค้างนานที่สุดในเกม แพ้ยกนั้นได้เลย |

## จุดอ่อนที่ตั้งใจให้มี

**ไม่มีท่ายิงเลยสักท่า** — ตัวเดียวในโรสเตอร์ที่ไม่มีอะไรออกไปไกลได้

**แพ้ทางคนที่ยืนห่างแล้วยิง** (Alecto) เต็ม ๆ และนั่นคือจุดอ่อนคลาสสิกของสายจับ
เลือด 115 ทนกว่าคนทั่วไปเพราะต้องเดินฝ่าเข้าไป แต่ยังห่างจาก Atlas ที่ 130

ท่าทุกท่าออกช้าที่สุดในเกม **จับพลาดทีเดียวคือจบ** — เล่นตัวนี้คือเล่นการพนัน

## ข้อควรรู้ตอนลงมือเขียน

1. **ท่าจับกันไม่ได้ = ของใหม่ในเอนจิ้น** ตอนนี้ทุกอย่างบล็อกได้หมด
   ต้องเพิ่มธง `unblockable` แล้วให้ `resolveHit` ข้ามเช็กบล็อก
   (แต่ยัง**ต้องเช็ก `invuln` อยู่** ไม่งั้นจับคนที่กำลังล้มได้ซึ่งพัง)

2. **ลูกโป่งเป็นสถานะใหม่ต่อ fighter** (เช่น `float`, `floatF`)
   **ต้องใส่ในตัวเทียบสถานะของ netplay ด้วย** ไม่งั้นสองเครื่องหลุดกันแบบไม่มีใครจับได้
   (เทสต์ netplay เทียบ lash / fires / armorLeft อยู่แล้ว เพิ่มตรงนั้น)

3. **แรงโน้มถ่วงครึ่งเดียวต้องอ่านจากตัวคนโดน ไม่ใช่ค่าคงที่ `PHYS`**
   `PHYS` ใช้ร่วมกันทั้งสองฝั่ง แก้ตรงนั้นจะลอยทั้งคู่

4. **`kb[1]` ของ jab1-2 ต้องเป็น 0** ถีบขึ้นแม้นิดเดียวคู่ต่อสู้จะลอย
   พอตกถึงพื้นกลายเป็นท่าล้มซึ่งมี invuln ติดมา จังหวะที่เหลือจะฟาดลม
   — กับดักนี้กัดมาแล้วสี่รอบ · ท่า `up` ที่ตั้งใจให้ลอยไม่นับ เพราะจบคอมโบตรงนั้นพอดี

5. **ห้ามตั้ง `active: 0`** `phase()` จะข้ามช่วง active ทั้งช่วง เฟรมอาร์ตกลางไม่ถูกวาด

6. **ท่าจับต้องมีเฟรม "คว้าไม่โดน" แยก** ไม่งั้นพลาดแล้วจะดูเหมือนจับติด
