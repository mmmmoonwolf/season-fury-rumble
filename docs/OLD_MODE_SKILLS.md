# สกิลจากโหมด 1v1 เดิม — บันทึกไว้ก่อนลบ

โหมด 1v1 ถูกลบออกในคอมมิตที่แนบไฟล์นี้มา เหลือแต่ SCRAMBLE
โค้ดยังอยู่ใน git history แต่ขุดยาก ไฟล์นี้เก็บ **ดีไซน์กับตัวเลขที่ผ่าน playtest มาแล้ว**
ไว้ใช้ตอนทำ Dear / KunJae / OAT ขึ้นใหม่บนเอนจิน SCRAMBLE

⚠️ ตัวเลขทั้งหมดเป็นของ **เอนจินเก่า** ซึ่งคิดเป็น **มิลลิวินาที** และใช้ฟิสิกส์ Phaser
SCRAMBLE คิดเป็น **เฟรม @60fps** และมีฟิสิกส์ของตัวเอง → แปลงหน่วยก่อนใช้ (`ms / 16.7 = เฟรม`)
และถือว่าเป็น "จุดตั้งต้นให้เถียง" ไม่ใช่ค่าที่ยกมาใช้ได้เลย เพราะบาลานซ์ขึ้นกับเอนจิน

## OAT — แปลงร่างไททัน

กลไกที่คุ้มที่สุดที่จะทำต่อ เพราะ SCRAMBLE มีของที่ต้องใช้เกือบครบแล้ว (หลอด ki + ช่องสกิล + ระบบสเกลอาร์ต)

**แก่น:** กดแล้วสลับเป็นร่างใหญ่ ตัว 1.2 เท่า ตีแรงแต่ช้า **มีหลอดเลือดแยกของตัวเอง** (150)
หลอดไททันแตก = กลับร่างเดิม + อมตะ 1 วิ กันโดนรุมทันที

| ค่า | สุดท้าย | เคยเป็น | ทำไมเปลี่ยน |
|---|---|---|---|
| ดาเมจ | ×1.6 | ×2 | หมัด 12/12/18 แรงเกินจนขังตาย |
| เหยื่อแข็งขั้นต่ำ | 400ms | 500ms | ตีทุก 0.35 วิ แต่เหยื่อแข็ง 0.5 วิ = **คอมโบไม่รู้จบ** |
| อยู่ในร่างได้ | 25 วิ | ไม่จำกัด | อยู่ถาวรจนหลอดแตก = ได้เลือด +75% กับดาเมจ ×2 ฟรี |
| คูลดาวน์ | 45 วิ | 30 วิ | รวมเวลาอยู่ในร่างแล้วพักจริง ~16 วิ |
| ขนาดตัว | ×1.2 | ×1.5 → ×1.35 | ผู้ใช้ขอให้เล็กลงสองรอบ |
| ออกท่าช้าลง | ×1.25 | — | เฉพาะหมัด 1-2-3 |
| hitstop | ×2.6 | — | 50 → 130ms + กล้องสั่น = น้ำหนักหมัด |

**บทเรียนสำคัญ:** "ตีถี่กว่าเวลาที่เหยื่อแข็ง" = คอมโบวนไม่มีที่สิ้นสุด ต้องเช็กสองค่านี้คู่กันเสมอ
(SCRAMBLE เจอปัญหาตระกูลเดียวกันมาแล้วตอนทำอัลติ — ถีบขึ้นนิดเดียวทำให้เหยื่อล้มแล้วอมตะ จังหวะถัดไปฟันลม)

**ท่าแปลงร่างใช้เวลา ~4 วิ** (เรืองแสง → ควันปะทุ + จอแฟลช 1.4 วิ → สลับร่าง 2.2 วิ → คำราม 4.1 วิ)
ทำเป็นภาพซ้อนบังตัวจริงไว้ข้างใต้ แล้วควันจางออกเผยร่างใหม่ — ยาวขนาดนี้ได้เพราะ**อมตะตลอดท่า**

**สกิลในร่างไททัน**
- S1 ง้างเตะ — ดาเมจ 14 (×1.6 = 22) เตะกระเด็นไกล 720px hitstun 800ms **มี super armor** คูลดาวน์ 8 วิ
- S3 ไททันบ้า — เรียกไททัน 3 ตัววิ่งข้ามจอ ชนใครลากไปด้วยจนสุดทางแล้วเหวี่ยงทิ้ง **กันทันไม่โดนลาก** · 1 ตัวลากได้ 1 คน

## KunJae — สลับอาวุธ

**แก่น:** ปุ่มเดียวสลับอาวุธ แล้ว **ท่ายืน + ตีพื้นฐาน + สกิล 1-3 เปลี่ยนทั้งชุด**
(ท่าวิ่ง/กระโดด/โดนตี ใช้ชุดเดียวกันทุกอาวุธ — ประหยัดอาร์ตไปเยอะมาก ข้อนี้ควรทำตาม)

| อาวุธ | ระยะ | ดาเมจ | ความเร็ว | หมายเหตุ |
|---|---|---|---|---|
| แส้ | ×3.2 | ×0.6 | ×1.4 (ช้า) | ต้องเงื้อ ระยะไกลแลกดาเมจต่ำ |
| ปืนสั้นคู่ | ×3.2 | ×0.6 | ×1 | ไกลเท่าแส้ แต่ออกไว |
| ลูกซองคู่ | ×2.4 | ×1.3 | ×1.6 (ช้าสุด) | สั้นกว่า แรงกว่า กระเด็น ×1.8 |

**บทเรียน:** ระยะไกลต้องแลกด้วยดาเมจต่ำเสมอ ไม่งั้นยืนเก็บฟรี — แส้/ปืน ×0.6 คือค่าที่ลงตัวหลังปรับหลายรอบ

**ที่ยังไม่ได้ทำ:** ไรเฟิล, ระเบิด

**หมายเหตุสำหรับ SCRAMBLE:** กลไกนี้กับแปลงร่างคือ *กลไกเดียวกัน* — "สลับว่าตอนนี้ใช้ตารางท่าชุดไหน"
ทำชั้น loadout รองรับครั้งเดียวได้ทั้งคู่ (`pickMove()` คืนชื่อท่าดิบ ๆ อยู่แล้ว เติมชั้นแมปได้ไม่ยาก)

## Dear V.2 — โหมดย่อง + ลูกโป่ง

**S2 โหมดย่อง** (6 วิ · คูลดาวน์ 30 วิ · ท่าเข้า 0.42 วิ อมตะตั้งแต่เฟรมแรก)
- **รับดาเมจแค่ 10%** เดินช้าลงเหลือ 80% ตัวโปร่ง 80% ให้รู้ว่าอยู่ในโหมด
- แทงได้รัว ~8.7 ที/วิ ดาเมจ 3 ต่อที แต่เป็น **true damage** (ทะลุการกัน)
- ไอเดียดี: เปลี่ยนจาก "ตัวถึกตีแรง" เป็น "ตัวบางตีถี่ทะลุการ์ด" คนละแกนกับไททัน

**S1 เขวี้ยงลูกโป่ง** (คูลดาวน์ 7 วิ) — ลอยช้าไปข้างหน้า ชนคนแรกแตกเป็นกระดาษสี
ดาเมจ 6 + สถานะ **มึนงง 2 วิ** (ยืนนิ่ง + ใช้สกิลไม่ได้ + ตีวืด พร้อมกันหมด)
2 วินาทีเลือกมาเพื่อให้เปิด S3 แล้วเดินไปถึงพอดี — **ตัวอย่างการตั้งเวลาสถานะจากคอมโบที่ตั้งใจ ไม่ใช่มั่ว**

**S2 วางลูกโป่งกับดัก** (คูลดาวน์ 10 วิ) — ระเบิดเมื่อแตะหรือครบ 2 วิ · **เลือกผลได้ 3 แบบก่อนวาง**
- พิษ — ระเบิด 6 แล้วติ๊ก 4 ทุก 0.5 วิ วงกว้าง 190 · เดินออกจากวงแล้วพิษยังติดต่ออีก 3 วิ
- กล่องผี — ดาเมจ 14 เด้งขึ้นสูง (knockbackY -820)
- ฝูงตัวตลก — 3 ตัวไล่หาเป้าใกล้สุดแล้วรุมแทง ไล่ไม่ทันก็จางหาย

**บทเรียน:** ท่าวางกับดักเดิมยาวไปและโดนขัดง่าย → เร่งเฟรม (791ms → 594ms) **และให้ super armor ทั้งท่า**
ท่าที่ยืนนิ่งนานต้องมี armor ไม่งั้นไม่มีใครกล้าใช้

## สรุปบทเรียนบาลานซ์ที่ใช้ได้ข้ามเอนจิน

1. **ตีถี่กว่าเวลาเหยื่อแข็ง = คอมโบไม่รู้จบ** เช็กคู่กันเสมอ
2. **ระยะไกลต้องแลกดาเมจต่ำ** ไม่งั้นยืนเก็บฟรี
3. **บัฟที่ไม่มีวันหมดเวลาคือบัฟฟรี** ร่างไททันต้องมีนาฬิกา ไม่ใช่รอหลอดแตกอย่างเดียว
4. **ท่ายาวต้องมี armor หรือ i-frames** ไม่งั้นเป็นท่าที่ไม่มีใครใช้
5. **ตั้งเวลาสถานะจากคอมโบที่ตั้งใจให้ต่อได้** ไม่ใช่เลือกเลขกลม ๆ
