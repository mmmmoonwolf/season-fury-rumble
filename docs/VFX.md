## ขาวดำบนพื้นดำ แล้วย้อมสีเอา

อาร์ตสั่งมาเป็น **ขาวดำล้วนบนพื้นดำสนิท** ซึ่งแปลงเป็นเท็กซ์เจอร์ได้โดย**ไม่ต้องคีย์สีเลยสักขั้นตอน**
(ต่างจากอาร์ตตัวละครทุกตัวที่ต้องเขียนตัวตัดพื้นเฉพาะตัว — Alecto ใช้พื้นที่หมวก · Atlas ใช้
ขอบ+ความสว่าง · Momus ใช้พื้นที่ตัว)

**ความสว่าง = ความทึบ** ส่วน RGB ทิ้งไปเป็นขาวล้วน เพราะชุดนี้ต้องใช้ได้ทั้งสองโหมดผสม:

| โหมด | ใช้กับ | ทำไม |
|---|---|---|
| `ADD` (ค่าเริ่มต้น) | ประกาย ไฟ แสง รอยฟาด | ขาว × สีที่ย้อม = เรืองแสง |
| `NORMAL` | **ควัน ฝุ่น** | ควันขาวในโหมด ADD บนฟ้ากลางวันจะหายสนิท |

ข้อสองเป็นกับดักที่เห็นก็ต่อเมื่อเปลี่ยนฉากเป็นกลางวันแล้วเท่านั้น

## รอยฟาดผูกกับ "ชื่อท่า" ไม่ใช่ต่อตัวละคร

ทุกตัวใช้ชื่อท่าเดียวกันหมด (`jab1`/`side`/`up`/…) `SLASH_DEFAULT` ตารางเดียวจึงครอบทั้งโรสเตอร์
ตัวที่อาวุธต่างจริงค่อยเขียนทับใน `CHAR_ART[x].slash`

**Alecto เขียนทับทั้งชุด** — แส้ยาวกว่าอาวุธอื่นทั้งโรสเตอร์ ต้องเป็นเส้นสะบัดยาว ไม่ใช่รอยดาบโค้ง
และ **ท่าปืนตั้งเป็น `null` ทุกท่า** — ปืนไม่ได้ฟาด มันยิง กระสุนเป็นตัวบอกอยู่แล้ว

### ขนาดรอยฟาดยึดความกว้าง hitbox จริง

```js
const reach = hb ? hb.w : 90;
scale: (reach / src.width) * 1.15
```

**รอยที่ใหญ่กว่าระยะที่โดนจริงคือการโกหกคนเล่น** เขาจะอ่านระยะผิดทุกครั้งที่เห็น
และมันปรับตัวเองตามท่า: จิ้มสั้นได้รอยสั้น แส้ยาวได้รอยยาว โดยไม่ต้องจูนทีละท่า

### ปล่อยเฟรมเดียวต่อหนึ่งท่า

ปล่อยที่ **เฟรมแรกของช่วง `active`** เท่านั้น
- ปล่อยทุกเฟรมที่ยังอยู่ในท่า → ซ้อนกันเป็นแผ่นทึบ
- ปล่อยตอนเริ่มท่า → มาก่อนกรอบโจมตีจริง ซึ่ง**สอนคนเล่นผิด**ว่าโดนได้ตั้งแต่ตอนเงื้อ

## ระเบิดประกายตอนหมัดเข้า

ทุกตัวเลขคูณตามน้ำหนักหมัด (`hitstop`) ไม่ใช่ค่าคงที่ — หมัดจิ้มกับไม้จบจึงต่างกัน**ทั้งภาพ**
ไม่ใช่ต่างแค่เวลาที่ภาพหยุด (`w = min(2.2, hs/5)` · 3 เฟรม → 0.6 · 16 เฟรม → 2.2)

## สองกับดักที่เจอตอนต่อ

**1 · ชื่อเมธอด `fx` ชนกับ `this.fx`**
`this.fx` เป็นอ็อบเจกต์ `graphics` ที่ตั้งไว้ใน `create()` อยู่แล้ว
เมธอดที่ชื่อซ้ำกับพรอเพอร์ตี้ของอินสแตนซ์จะถูก**ทับเงียบ ๆ** แล้วพังตอนรันเท่านั้น
(`this.fx is not a function`) เปลี่ยนชื่อเป็น `emit`

**2 · ADD บนฟ้าสว่างอิ่มตัวทันที**
รอบแรกตั้ง alpha 0.85 + สเกลใหญ่ + `spark()` เดิมยังยิงซ้อนอยู่ = จอขาวโพลนกลบตัวละครทั้งสองคน
แก้ด้วยการลบ `spark()` เดิมออกจาก event `hit` แล้วลด alpha ลงครึ่งหนึ่ง

## อนุภาคใช้พูลซ้ำ

`_fxPool` / `_fxLive` — หมดอายุแล้วคืนเข้าพูล ไม่สร้าง/ทิ้งอ็อบเจกต์ทุกนัด
ทั้งหมดเป็นการวาดล้วน **ใช้ `Math.random` ได้เต็มที่** เพราะ sim เดินด้วยเลขเฟรมล้วน
เอฟเฟคสองเครื่องต่างกันได้ ไม่มีผลกับผลการต่อสู้
