# ORPHEUS — ผังสกิลที่ล็อกแล้ว (ยังไม่เขียนโค้ด)

**The Fury of the Long Echo** · สายวางเสียงสะท้อน · นักดนตรีผมยาวถือกีตาร์

ชื่อมาจากนักดนตรีในตำนานกรีกที่เสียงเพลงสะกดได้ทั้งสัตว์ ต้นไม้ และก้อนหิน
ลงไปถึงยมโลกเพื่อพาคนรักกลับมาแต่**เหลียวกลับไปมอง**เลยเสียเธอไปตลอดกาล
พอถูกฉีกร่างออกเป็นชิ้น ๆ **หัวของเขายังร้องเพลงต่อ** — นั่นคือแก่นของตัวนี้:
**สิ่งที่เขาทำไปแล้ว ยังทำงานอยู่**

---

## กลไกประจำตัว: เสียงสะท้อน (Echo)

**ท่าที่เขาฟาดไป จะย้อนกลับมาฟาดซ้ำที่เดิมอีกหนึ่งวินาทีให้หลัง**

ไม่ใช่กระสุนที่วิ่งไปหาคู่ต่อสู้ และไม่ใช่กองไฟที่วางทิ้งไว้ที่อื่น
แต่คือ**ร่างเงาของตัวเขาเองในอดีต** ยืนอยู่ตรงจุดที่เขาเพิ่งยืน แล้วออกท่าเดิมซ้ำ

| | ค่าที่ตั้งไว้ |
|---|---|
| หน่วงก่อนสะท้อน | **60 เฟรม (1 วินาที)** |
| ดาเมจ | **50%** ของท่าต้นฉบับ |
| จำนวนที่ค้างพร้อมกันได้ | **3 เสียง** (อัลติเพิ่มเป็น 5) |
| ถีบขึ้น | **0 เสมอ** — สะท้อนเองไม่มีวันจับลอย |
| มองเห็นไหม | เห็น เป็นร่างจาง ๆ ที่ค่อย ๆ สว่างขึ้นก่อนลั่น |

### ทำไมกลไกนี้ถึงไม่ซ้ำกับใคร

| ตัว | ถามคู่ต่อสู้ว่า |
|---|---|
| Nyx | "ตอนนี้ฉันอยู่ไหน" (วาร์ป) |
| Helios | "จะหนีออกจากระยะนี้ยังไง" (กดดันติดตัว) |
| Alecto | "จะเดินผ่านตรงนั้นยังไง" (ปฏิเสธพื้นที่) |
| Atlas | "จะหยุดฉันยังไง" (เกราะ) |
| **Orpheus** | **"เมื่อกี้ฉันยืนตรงไหน"** |

เป็นแกนใหม่ทั้งแกน — ไม่ใช่พื้นที่ ไม่ใช่ความอึด ไม่ใช่ความเร็ว แต่คือ**เวลา**
คู่ต่อสู้ต้องจำไม่ใช่แค่ว่าเขาอยู่ไหน แต่ต้องจำว่า**เมื่อกี้เขาอยู่ไหน**ด้วย

### ทางแก้ของฝั่งตรงข้าม (ตั้งใจให้มีครบ)

- **เห็นล่วงหน้าเต็ม 1 วินาที** ร่างเงาโผล่ทันทีที่เขาออกท่า ไม่ใช่โผล่ตอนตี
- **อยู่กับที่** เดินออกจากจุดนั้นก็ไม่โดน
- **จับลอยไม่ได้** ถีบขึ้นเป็น 0 ทุกเสียง สะท้อนล้วน ๆ ฆ่าไม่ได้
- **มีเพดาน 3 เสียง** วางที่สี่แล้วเสียงแรกหายไป กดรัวไม่ได้กำไร
- **ตัวเขาเปราะปกติ** เลือด 100 ไม่มีเกราะ ไม่มีวาร์ป พลาดทีกินคอมโบเต็ม

> **ข้อควรระวังตอนคิดตัวเลข:** ดาเมจสะท้อนไม่เข้าสูตรลดดาเมจคอมโบ
> เพราะเว้นระยะห่างกันเกินกว่าตัวนับคอมโบจะต่อติด (บทเรียนจากท่ายืนยิงของ Alecto
> ที่คำนวณไว้ 19 แต่ออกมาจริง 46) ต้องตั้งเลขดิบให้ต่ำตั้งแต่แรก

## จุดอ่อนที่ตั้งใจให้มี

**พลังเต็มที่ต้องใช้เวลาเซ็ต — ถ้าโดนไล่จี้ตั้งแต่ต้นจะไม่มีอะไรเลย**

เขาแพ้ทางคนที่ไม่ยอมให้เขาได้ยืนนิ่ง (Helios) และคนที่เดินฝ่าเข้ามาเฉย ๆ (Atlas)
ชนะทางคนที่ชอบเว้นระยะแล้วค่อยเข้า เพราะจังหวะที่เข้ามาคือจังหวะที่เสียงเก่าลั่นพอดี

## ท่าปกติ — กีตาร์เป็นทั้งเครื่องดนตรีและขวาน

| ท่า | ทำอะไร |
|---|---|
| jab1-2-3 | เหวี่ยงกีตาร์สามจังหวะ · **jab3 ทิ้งเสียงสะท้อน** |
| side | ตวัดคอกีตาร์ไปข้างหน้าพร้อมคลื่นเสียงสั้น ๆ · **ทิ้งเสียงสะท้อน** |
| up | ยกคอกีตาร์สอยขึ้น (สวนคนกระโดด) |
| down | กวาดตัวกีตาร์ติดพื้น |
| nair / sair / dair | เหวี่ยงกลางอากาศสามทิศ |
| ถอยหลัง | กระโดดถอยสั้น ๆ พร้อมดีดสายหนึ่งที — **ทิ้งเสียงสะท้อนไว้ตรงที่เพิ่งยืน** |

ท่าถอยหลังสำคัญกว่าที่คิด: ตัวนี้ต้องออกจากจุดที่วางเสียงไว้ให้ได้
ไม่งั้นตัวเองจะติดอยู่กับกับดักตัวเอง (บทเรียนตรงจาก "ขาตาย" ของ Alecto)

## สกิล

**1 · Power Chord (คอร์ดหนัก)** — ตีคอร์ดเต็มแรงลงข้างหน้า
ดาเมจหนักที่สุดในบรรดาท่าเดี่ยว และ**ทิ้งเสียงสะท้อนที่แรงที่สุด**
นี่คือปุ่มหลักที่ใช้วางเสียง คูลดาวน์สั้น

**2 · Feedback (ฟีดแบ็ก)** — **ท่าสวนกลับ** ยกกีตาร์รับ
ถ้ามีอะไรมาโดนในช่วงรับ: ไม่เจ็บเลย แล้ว**แปลงแรงนั้นเป็นเสียงสะท้อนที่ตัวคนตี**
หน้าต่างรับ 10 เฟรม · พลาดแล้วค้างยาว · คูลดาวน์ยาวสุดในเกม

> ทั้งโรสเตอร์ยังไม่มีใครมีท่าสวนกลับเลย — Nyx หนีด้วยวาร์ป Helios กดทับ
> Alecto ปฏิเสธพื้นที่ Atlas ทนเอา อันนี้คือคำตอบด้านรับแบบที่ห้าที่ยังว่างอยู่
> และตรงคอนเซ็ปต์ที่สุด เพราะฟีดแบ็กคือกีตาร์รับเสียงเข้าไปแล้วคายกลับออกมา

**3 · Last Encore (อัลติ · อังกอร์สุดท้าย)** — ตั้งท่าโซโล่ 3 วินาที
ระหว่างโซโล่: ยิงคลื่นเสียงไปข้างหน้าเป็นจังหวะ ๆ และ**เสียงสะท้อนที่ค้างอยู่ลั่นซ้ำทุกจังหวะ**
เพดานเสียงขึ้นเป็น 5 · จบด้วยคลื่นกว้างออกสองข้าง
**เดินได้ระหว่างโซโล่** (ช้าลง) — ตั้งใจใส่มาตั้งแต่แรกเพราะบทเรียน "ขาตาย" ของ Alecto

ยิ่งเซ็ตเสียงไว้เยอะก่อนกด อัลติยิ่งแรง — เป็นไม้จบที่ต้องทำการบ้านมาก่อน
ไม่ใช่ปุ่มกดแล้วชนะ

## ข้อควรรู้ตอนลงมือเขียน

1. **เสียงสะท้อนใช้ระบบกระสุนเดิมได้เลย** ไม่ต้องสร้างระบบใหม่
   กระสุนที่ `vx = 0` + ฟิลด์ `delay` + อายุสั้น ๆ = เสียงสะท้อนพอดี
   ข้อดีคือมันอยู่ในตัวเทียบสถานะของ netplay อยู่แล้ว ไม่ต้องเพิ่มอะไรให้สองเครื่องหลุดกัน

2. **`kb[1]` ของเสียงสะท้อนต้องเป็น 0 ทุกตัว** ถ้าถีบขึ้นแม้นิดเดียวคู่ต่อสู้จะลอย
   พอตกถึงพื้นกลายเป็นท่าล้มซึ่งมี invuln ติดมา — กับดักนี้กัดมาแล้วสี่รอบ

3. **ห้ามตั้ง `active: 0`** `phase()` จะข้ามช่วง active ทั้งช่วง เฟรมอาร์ตกลางไม่ถูกวาด

4. **ท่าโซโล่ต้องเดินได้ตั้งแต่แรก** ใช้ธง `mobile` ที่ทำไว้ตอนแก้ Alecto

5. **ตัวนับคอมโบไม่คุ้มครองเสียงสะท้อน** ตั้งเลขดิบให้ต่ำ แล้ววัดด้วยเทสต์จริง
