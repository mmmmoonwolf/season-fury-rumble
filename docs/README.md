## ที่อื่น

- `vendor/README.md` — ทำไมเก็บ Phaser/PeerJS ในรีโป ไม่ดึงจาก CDN
- `vendor/fonts/README.md` — ฟอนต์ที่โค้ดอ้างไว้หกจุดแต่ไม่เคยถูกโหลด + สัญญาอนุญาต OFL
- `art_prompts_*.md` (รากรีโป) — prompt ที่ใช้เจนอาร์ต แยกตามตัวละคร/รอบ
  · ใบล่าสุดคือ `art_prompts_dear.md` (ชีตใหม่ของ DEAR 7 ใบ ยังไม่ได้เจน)
- `docs/archive/` — เอกสารส่งต่อของรุ่นก่อน ๆ เก็บไว้อ้างอิง ไม่ได้อัปเดตแล้ว

## เทสต์

`cd game && bash tools/tests/run_all.sh` — ตอนนี้ **1567 ข้อ**

รันอัตโนมัติบน GitHub Actions ทุกครั้งที่ push และ **เป็นด่านก่อนขึ้นเว็บ**
เทสต์แดง = ไม่ deploy (ดู `.github/workflows/`)

วิธีเขียนเทสต์ในโปรเจกต์นี้: **ใส่บั๊กกลับเข้าไปดูว่ามันแดงจริงไหม**
เทสต์ที่ไม่เคยเห็นสีแดงคือเทสต์ที่ยังไม่รู้ว่าใช้ได้หรือเปล่า
(เคยเจอของจริง: เทสต์ปุ่มก๊อปรหัสห้องอ่านแค่ข้อความในโค้ด ตัดตรรกะทิ้งแล้วไม่แดง
เพราะคำที่ค้นหายังอยู่ในไฟล์ แค่ไม่มีใครเดินไปถึง)

## ชื่อตัวละคร: ชื่อเล่นของคนเล่น + ฉายาเป็นชื่อในตำนาน

เกมนี้ทำให้กลุ่มเพื่อนเล่นกันเอง ชื่อที่ขึ้นตอนชนะจึงเป็น**ชื่อเพื่อน** ไม่ใช่ชื่อเทพ

| `id` (ห้ามเปลี่ยน) | ชื่อที่โชว์ | ฉายา |
|---|---|---|
| `nyx` | BOMB | Nyx |
| `helios` | MARCH | Helios |
| `alecto` | KUNJAE | Alecto |
| `atlas` | TEEMEE | Atlas |
| `orpheus` | OAT | Orpheus |
| `momus` | DEAR | Momus |

**`id` ไม่เปลี่ยนเด็ดขาด** — มันคือคีย์ของอัตลาส (`scnyx`) ชื่อไฟล์ชีตใน `tools/`
และค่าที่ส่งข้ามเน็ตตอนเลือกตัว เปลี่ยนเมื่อไหร่ = อาร์ตหายทั้งตัว
และแท็บที่เปิดค้างอยู่เล่นกับแท็บใหม่ไม่ได้
