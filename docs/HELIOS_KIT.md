## สกิล 2 (ใหม่) · **SKY DRIVE** — ยกคาง ตีกลางอากาศ ตบลงพื้น ต่อได้

แทน `Knee Drive` เดิม (พุ่งเข่าดันออก) ทั้งหมด

### สามจังหวะ กดปุ่มเดียว

| ท่า | ชื่อ | เงื้อ | ออก | ค้าง | ดาเมจ | หมายเหตุ |
|---|---|---|---|---|---|---|
| sky1 | ยกคาง | 7 | 4 | 10 | 5 | `kb: [1, -17]` · `imp: { vy: -13 }` **เขาลอยตามขึ้นไปเอง** |
| sky2 | ศอก | 3 | 3 | 3 | 3 | `floaty` · `kb: [1, -2]` |
| sky3 | หมัดเหวี่ยง | 3 | 3 | 3 | 3 | `floaty` · `kb: [1.5, -2]` |
| sky4 | หลังมือ | 3 | 3 | 4 | 3 | `floaty` · `kb: [2, -2]` |
| sky5 | ทุบลง | 5 | 5 | 6 | 6 | `kb: [2, **+14**]` · **`bounce`** · `untilLand` · `landLag: 10` |

**รวม 20 ดาเมจก่อนหักสเกลคอมโบ** · คูลดาวน์ 210 เฟรม (3.5 วิ)

### หัวใจของสกิลนี้คือ "เด้งพื้น" ไม่ใช่การลอย

**ตอนนี้ท่าตบลงพื้นทุกท่าในเกมจบคอมโบทันที** เพราะคนที่ตกลงมาในสถานะ hitstun
จะเข้า `knockdown` แล้วได้ **อมตะ 30 เฟรม** (`core.js` ราวบรรทัด 2059):

```js
f.setState('knockdown'); f.stun = PHYS.knockdownFrames; f.invuln = PHYS.knockdownFrames + 2;
```

นั่นคือเหตุผลที่ "ลงพื้นมาคอมโบต่อ" **ยังทำไม่ได้เลยในเกมตอนนี้** ไม่ว่าจะออกแบบท่ายังไง

ทางแก้: ธง `bounce` บนท่าตบ — คนที่โดนท่านี้แล้วตกถึงพื้น **เด้งขึ้นแทนที่จะล้ม**
ยังอยู่ใน hitstun ต่อ เขาจึงต่อได้จริง

> **เอนจิ้นมีของแบบนี้อยู่แล้วหนึ่งชุด** — การเด้งกำแพง (`wallBounced`) ทำงานแบบเดียวกันเป๊ะ
> รวมถึงการล้างธงตอนคอมโบจบ (`d.wallBounced = false` ตอน `comboEnd`)
> **เด้งพื้นคือกระจกเงาของมัน** ก๊อปโครงมาแล้วเปลี่ยนแกนจาก x เป็น y

**เด้งได้ครั้งเดียวต่อหนึ่งคอมโบ** (ธง `bounced` ล้างพร้อม `wallBounced`) ไม่งั้นจะวน
sky → เด้ง → sky → เด้ง ไม่รู้จบ ซึ่งเป็นสิ่งที่ระบบลดดาเมจตามคอมโบมีไว้กันอยู่แล้ว
แต่ไม่ควรพึ่งอย่างเดียว

### ลงพื้นแล้วต่ออะไร

`sky5` ติด **`refresh: ['rush1']`** — คุณสมบัติเดียวที่ยกมาจาก `Knee Drive` เดิม

แปลว่าจบชุดลอยแล้ว **Chain Rush พร้อมใช้อีกครั้งทันที** ลูปเต็มของเขาคือ:

> รัว Chain Rush → ยกคาง → ตีสี่ทีกลางอากาศ → ตบลงพื้น → เขาเด้ง → **รัว Chain Rush อีกรอบ**

นี่คือคอมโบที่ยาวที่สุดในเกม และมันควรเป็นของเขา เพราะเขาคือตัวที่ไม่มีอย่างอื่นเลย
นอกจากหมัดกับเท้า

### ทำไมต้องมี `imp: { vy: -13 }` บนท่ายกคาง

ท่ายกคางที่มีอยู่แล้ว (`up`, `rushEndU`) ใช้ `jumpCancel` — **คนเล่นต้องกดกระโดดตามเอง**
ซึ่งเป็นการบ้านที่ถูกต้องสำหรับท่าตีปกติ

แต่สกิลนี้ต้องเป็น **"กดทีเดียวได้ทั้งชุด"** ไม่งั้นมันคือ `up` ที่ยาวกว่าเดิม ไม่ใช่สกิลใหม่
เขาจึงลอยตามขึ้นไปเอง และชุดกลางอากาศต่อกันเองด้วย `autoChain`

### ทางแก้ของฝั่งที่โดน

- **ยกคางเงื้อ 7 เฟรม** ช้ากว่า `up` (6) และช้ากว่าทุกท่าแย็บของเขา — เห็นแล้วกันทัน
- **ค้าง 10 เฟรมถ้าฟันลม** และเขาลอยอยู่กลางอากาศโดยไม่มีอะไรกัน = โดนสวนเต็ม ๆ
- **เด้งพื้นได้ครั้งเดียวต่อคอมโบ** รอบสองเป็นการล้มปกติที่มีอมตะ
- สเกลลดดาเมจตามคอมโบทำงานตามปกติ — ถึงฮิตที่ 7 เหลือ 50%

## "อะนิเมชั่นให้ลื่น" — ทำได้จริง และไม่ต้องเพิ่มเฟรม

ท่าโจมตีในเกมนี้ใช้ **3 เฟรมต่อท่า** เลือกด้วย `phase()` ไม่ใช่เล่นตามเวลา:

```js
const i = { startup: 1, active: 2, recovery: 3 }[f.phase()] ?? 1;
```

ตั้งใจออกแบบไว้แบบนี้เพราะ **เฟรม "สุดแขน" ต้องโผล่ตรงกับช่วงที่กรอบโจมตีมีผลจริงเป๊ะ**
ถ้าเล่นเป็น animation ตามเวลา มันจะคลาดกับเฟรมเดต้าเสมอ

### ทางที่เลือก: ต่อรอยต่อ ไม่ใช่เพิ่มเฟรม

ชุดรัว 5 จังหวะ = **15 รูปที่วาดแยกกันอยู่แล้ว** ความกระตุกไม่ได้มาจาก "เฟรมน้อย"
แต่มาจาก **รอยต่อ** — เฟรมค้างของจังหวะที่ 1 ตัดไปเฟรมเงื้อของจังหวะที่ 2 แบบไม่มีอะไรเชื่อม

**ทางแก้เป็นเรื่องอาร์ตล้วน ๆ ไม่ต้องแตะโค้ดเลย:**

> **วาดให้ "เฟรมค้างของจังหวะที่ N" กับ "เฟรมเงื้อของจังหวะที่ N+1" เป็นท่าเดียวกัน**
> มือที่ชักกลับจากแย็บ = มือที่กำลังจะออกหมัดขวา · น้ำหนักตัวไหลต่อ ไม่ดีดกลับมาตั้งหลัก

ทำแบบนี้ตาจะอ่านทั้งชุดเป็นการเคลื่อนไหวเดียว ทั้งที่ยังเป็น 3 เฟรมต่อท่าเหมือนเดิม
**ได้ความลื่นมาฟรี ไม่เสียเฟรมเพิ่มสักรูป**

### ทางที่ไม่เลือก (และทำไม)

เพิ่มเป็น 5 เฟรมต่อท่าเฉพาะชุดสกิลก็ทำได้ (แก้ตารางแปลง `phase()` เป็นเฟรม)
แต่ **ชุดสกิลของเขามี 14 ท่า → จาก 42 รูปเป็น 70 รูป** ซึ่งเป็นต้นทุนอาร์ตที่สูงมาก
สำหรับสิ่งที่การต่อรอยต่อให้ได้เกือบหมดแล้ว

**ถ้าทำรอยต่อแล้วยังรู้สึกกระตุกจริง ค่อยกลับมาคุยข้อนี้** — อย่าจ่ายก่อนวัด

## อาร์ต — ใช้ตามภาพอ้างอิงที่ให้มา

เก็บไว้ที่ `art_reference/helios_redesign_TURNAROUND.png`

ภาพนี้เป็น **turnaround เต็มชุด** (8 มุมตัว + 8 มุมหัว + สีหน้า 4 แบบ + ท่าตั้งการ์ด 5 ท่า)
ซึ่งเป็นของอ้างอิงที่ดีที่สุดเท่าที่เคยได้มาในโปรเจกต์นี้ — **แนบไปกับทุก prompt**

| | |
|---|---|
| ผม | ดำ หนามแหลมฟูขึ้นด้านบน **ต้องแนบกะโหลก เห็นไรผม** |
| ตัว | เสื้อยืดดำรัดรูป แขนสั้น เห็นกล้าม |
| ขา | **กางเกงขาวหลวมมาก** ปลายขาบานคลุมข้อเท้า |
| เอว | ผ้าคาดดำ ปลายห้อยข้างซ้าย |
| มือ | ถุงมือดำไร้นิ้ว พันข้อมือ |
| เท้า | บูตดำหุ้มข้อ |
| หน้า | แผลเป็นเล็กที่แก้ม · สีหน้านิ่งจนถึงยิ้มมุมปาก |

### ข้อได้เปรียบของชุดสีนี้ (และกับดักของมัน)

**ท่อนบนดำ ท่อนล่างขาว** = เงาของเขาอ่านออกง่ายที่สุดในโรสเตอร์ บอกได้ทันทีว่าหันทางไหน

**แต่กางเกงขาวคือความเสี่ยง** — พื้นของเวทีอยู่ราว 150-190 บนสเกล 0-255
ถ้ากางเกงสว่างกว่านั้น **ครึ่งล่างของเขาจะจมหายไปกับพื้น** ซึ่งเป็นปัญหาที่ตัวตลกเคยเจอมาแล้ว

> 📌 **ต้องวัดจริงตอนขั้น 0** ถ้าท่อนล่างวัดได้เกิน ~140 ให้เจนใหม่โดยสั่งให้กางเกง
> เป็นสีเทาอ่อน/ครีมหม่นแทนขาวสว่าง และเพิ่มเงาใต้พับผ้าให้เข้มขึ้น
> (วิธีวัดเดียวกับที่ใช้กับ DEAR — ดู `art_prompts_dear.md` หัวข้อ "ผลวัดขั้น 0")

### สิ่งที่ห้ามใส่

- **ห้ามมีเอฟเฟกต์ใด ๆ** ไม่มีลมหมัด ไม่มีประกาย ไม่มีเส้นความเร็ว — เกมวาดเองหมด
- **ห้ามมีอะไรหลุดออกจากตัว** ตัวตัดชีตทิ้งก้อนที่ไม่ติดกับตัว ปลายผ้าคาดต้องติดอยู่กับเอว
- **ห้ามวาดคู่ต่อสู้**
